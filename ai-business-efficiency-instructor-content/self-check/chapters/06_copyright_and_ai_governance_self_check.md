## 先に行うこと

先に自分の`06_公開前レビュー.md`を保存してください。成果物を作る前に例を読み写さず、次の順で使います。

1. 非公開のチラシ案、制作記録、停止条件を自分で作る。
2. 下のヒントを1つずつ開く。
3. 判断できない箇所だけ成果物例と比較する。
4. 差分を1点だけ修正し、入力から公開前までを再確認する。

## 成果物例を見る前の注意

- 本書の例は法的助言でも公開許可でもありません。著作権、商標、肖像、パブリシティ、不正競争、広告表示、契約等の判断は、地域、素材、生成過程、用途、公開方法で変わります。
- 演習の組織、講座、会場、人物、画像は一から作った架空例です。実在する企業、人物、作品、キャラクター、ブランド、ロゴを生成・模倣しません。
- ChatGPTとCanva AIには、完全な架空情報だけを入力します。実在者情報を伏せ字にしたものは使いません。
- 完成物は自習用の非公開下書きです。外部公開、SNS投稿、印刷発注、広告配信を行いません。
- Canvaの機能名、プラン、AI利用条件、素材ライセンス、データ設定は変わります。学習日に最新の公式情報と契約を確認します。
- AI出力は人間が確認します。実利用は法務、知的財産、ブランド、個人情報等の担当者または専門家へ確認します。
- 組織利用では承認済み環境だけを使い、教材に記載された完全な架空データだけを扱います。未承認の場合は紙またはMarkdownへ切り替えます。

## 利用環境の記入例

| 項目 | 記入例 |
|---|---|
| ChatGPT | 本人が条件を確認した個人用、または組織が承認した業務用アカウント。架空設定だけを入力 |
| Canva | 承認済み組織ワークスペース。AI機能と素材利用を管理者が確認 |
| 共有 | 作成者とレビュー担当者だけ。公開リンクは作らない |
| 入力禁止 | 実在人物・企業・商品・キャラクター・ロゴ、顧客情報、未公開資料 |
| 記録 | 使用機能、プロンプト、生成日時、選択素材、編集、確認者、停止判断 |
| 利用不可時 | 本章の文章例とワイヤーフレーム例を使い、紙またはMarkdownへ切替 |

### 準備段階の記入例

```text
作成物：自習中だけで見る架空チラシの下書き
公開状態：非公開
入力：教材にある架空設定だけ
AIの役割：原稿案と抽象画像案を作る
人の役割：事実、権利、類似、偏り、共有、公開可否を判断する
利用できない場合：同じプロンプトとレビュー表を紙上で作成する
```

## 見本ケースの成果物例

### 3.1 完全な架空設定

```text
主催：青空ラーニングスタジオ（架空）
講座名：初めての業務AI整理講座（架空）
開催日：20XX年10月15日
会場：みらい会議室（架空）
対象：生成AIを初めて業務で試す人
目的：安全な入力判断と人間レビューを体験する
```

### 3.2 ChatGPT原稿案の例

```text
初めての業務AI整理講座

生成AIを業務で試す前に、入力してよい情報を見分け、
AIが作った内容を人が確認する流れを体験します。

対象：生成AIを初めて業務で試す人
内容：安全な入力判断／業務の分解／人間レビュー
開催日：20XX年10月15日
会場：みらい会議室
主催：青空ラーニングスタジオ

申込方法・料金・定員・登壇者情報：要確認
※名称、日付、会場を含め、すべて教材用の架空設定です。公開・申込はできません。
```

この案は、元設定にない実績、推薦、効果、統計を作らず、不足情報を「要確認」としています。「必ず効率化」「満足度98%」等が追加された場合は削除します。

### 3.3 Canva AI用の画像指示例

```text
架空の社内研修案内に使う、青と白を基調とした抽象的な幾何学模様。
人物、文字、ロゴ、商品、キャラクター、ブランドを含めない。落ち着いた業務向け。
```

### 3.4 生成直後の確認記録例

| 確認項目 | 記録例 |
|---|---|
| 人物・顔 | 含まれていない |
| 文字・ロゴ | 意図しない記号があったため、その案は不採用 |
| 既存表現との類似 | 特定対象を想起した案は使わず、単純な図形案へ変更 |
| 類似画像検索 | 一致なしでも権利クリアランス完了とは記録しない。検索語・確認日・未確認事項を残す |
| 編集 | 色・形・配置を変更しても元素材の権利や類似が自動的に解消しないため、編集前後を確認対象にする |
| 固定観念・不快表現 | 属性表現がないことを確認 |
| プロンプト | 上記全文を保存 |
| 機能・日時 | 当日の画面表示名と生成日時を記録 |
| 共有状態 | 作成者とレビュー担当者だけ |

生成できたことは利用許可を意味しません。問題を安全に修正できない場合は、その案を使いません。

## 自分で行う練習の成果物例

### 4.1 非公開チラシのワイヤーフレーム例

```text
┌──────────────────────────┐
│［青と白の抽象的な幾何学模様］                   │
│                                              │
│ 初めての業務AI整理講座                         │
│ 安全な入力判断と人間レビューを体験する架空研修   │
│                                              │
│ 対象：生成AIを初めて業務で試す人                │
│ 内容：入力判断／業務分解／人間レビュー           │
│ 20XX年10月15日・みらい会議室                    │
│                                              │
│ 主催：青空ラーニングスタジオ                    │
│ ※すべて架空。非公開の教材用下書きです。          │
└──────────────────────────┘
```

申込ボタン、URL、QRコード、推薦コメント、実績、料金等は元設定にないため置きません。

### 4.2 制作記録例

| 工程 | 記録する内容 | 成果物例 |
|---|---|---|
| 入力 | 入力元と利用権限 | 教材の架空設定。第三者素材なし |
| ChatGPT | プロンプト、出力、修正 | 未確認情報を追加しない指示。申込方法等を要確認へ変更 |
| Canva AI | 機能名、画像プロンプト、生成日時 | 当日の表示名と抽象画像指示を記録 |
| 素材 | 素材ID、ライセンス、確認日 | ライブラリ素材は使わず、AI生成の抽象案のみ |
| 編集 | 人が変更した箇所 | 架空・非公開表示、文字サイズ、色のコントラストを調整 |
| 権利確認 | 類似検索・確認者・未確認事項 | 類似検索は手掛かりとして実施。権利クリアランスや非侵害の保証にはしていない |
| 共有 | 閲覧・編集権限 | 作成者とレビュー担当者のみ |
| 公開 | 状態と停止条件 | 非公開。専門確認と責任者承認がないため公開しない |

### 4.3 公開前リスク記録例

| 段階 | 確認したこと | 発見例 | 対応 |
|---|---|---|---|
| 入力 | 入力する権利、機密・個人情報 | 第三者素材は未使用 | 架空設定だけを維持 |
| 生成 | 既存表現との類似、人物、ブランド、偏り | ロゴのような記号が生成された | その案を不採用にし、単純図形へ再生成 |
| 編集 | 統計、推薦、実績、素材条件。編集前の権利論点が残っていないか | ChatGPTが申込方法を補おうとした。画像を編集しただけで権利確認済みとした | 「要確認」へ戻す。画像の権利確認は編集前後を対象にする |
| 公開前 | 規約、契約、表示、承認、共有 | 専門確認と最終承認がない | 非公開のまま終了 |

### 4.4 停止条件の例

- 実在人物、既存キャラクター、ブランド、ロゴに似た要素を判断できない
- 入力素材またはCanva素材の利用条件を確認できない
- 類似画像検索で一致がないこと、または人間・AIで編集したことだけを根拠に公開しようとしている
- 未確認の統計、推薦、実績、効果が残っている
- 誤認、差別、固定観念、アクセシビリティ上の問題を解消できない
- AI利用表示、契約、共有範囲、責任者承認が不明である
- 法務・知的財産等が求める確認を完了していない

停止した後は、修正、素材差替え、企画変更、利用中止、専門家相談のいずれかを記録します。

## 自己レビューの記録例

| レビュー指摘 | 作成者の対応 | 理由 |
|---|---|---|
| AI画像に企業ロゴのような記号がある | 画像を差し替える | 特定のブランドとの関係を判断できないため |
| 「業務効率が必ず上がる」と書かれている | 元設定に沿う目的説明へ変更 | 効果を確認しておらず誤認を招くため |
| 申込先がない | 勝手にURLを作らず「要確認」のままにする | 存在しない申込先を作らないため |
| 架空表示が小さい | 見やすい位置と大きさへ変更 | 実在の募集と誤解されにくくするため |
| 外部共有リンクが有効 | 共有を限定へ戻す | この演習は非公開下書きだから |

### 専門家へ渡す質問例

- 使用したCanvaの機能・プランと用途に、どの最新規約が適用されますか。
- 生成画像の類似性を判断するため、プロンプト、生成過程、比較対象のどの資料が必要ですか。
- 類似画像検索と編集を行った後も残る権利論点は何で、権利クリアランスには追加で何が必要ですか。
- Canvaライブラリ素材を使う場合、編集、広告、再配布、表示にどの条件がありますか。
- AI利用の表示、制作記録、顧客との契約上の説明は必要ですか。
- 公開前に著作権、商標、肖像、広告表示、個人情報のどの担当確認が必要ですか。

質問には入力、プロンプト、生成日時、使用機能、素材情報、編集履歴、用途、公開先を添えます。相談した事実だけでなく、確認できた条件と未解決事項を記録します。

人物に関係する情報や表現を別の業務で扱う場合は、健康・障害等の漏えいが大きな不利益につながり得る**要配慮性**と、個人情報を収集・利用・AI処理してよい理由である**法的根拠**も確認します。「AI利用が社内承認済み」だけを法的根拠とせず、個人情報・法務担当者や専門家へ引き継ぎます。本演習ではその判断を避けるため、人物と実データを使いません。

## 振り返りの記入例

- ChatGPTが追加しかけた情報：申込方法と効果表現。元設定にないため削除または要確認とした。
- Canvaで迷った点：ロゴのような記号と、既存デザインを連想する配色。単純な抽象図形へ変更した。
- 人が少し直しても安全とは限らない理由：入力権利、類似、素材条件、誤認、公開条件は別々に残るから。
- 実務で残す証跡：入力元、プロンプト、生成日時、機能、素材、編集、確認者、承認、公開範囲。
- 相談先：法務、知的財産、広報・ブランド、個人情報、業務責任者。

## 一致必須の内容と改善例

| 一致必須の観点 | 完成した状態 | 改善例 |
|---|---|---|
| 架空データ | 実在対象を元にせず一から設定する | 伏せ字の実案件なら演習用架空設定へ置き換える |
| ChatGPT原稿 | 元設定にない事実を要確認にする | 実績・推薦・統計を追加した場合は削除し、根拠欄を作る |
| Canva生成物 | 見た目だけでなく類似・偏り・記号を確認する | 「きれいだから採用」なら拡大確認と比較レビューを行う |
| 権利クリアランス | 類似検索・編集の限界を記録し、素材権限・規約・第三者権利を別に確認する | 「一致なし」「編集済み」だけなら未確認として公開を止める |
| 素材条件 | AI規約と素材ライセンスを分けて確認する | 商用利用可だけなら第三者権利と用途条件を追加する |
| 共有・公開 | 非公開を確認し、停止できる | 外部リンクがあれば解除し、権限画面を記録する |
| 人間レビュー | 元情報、専門性、修正・停止権限、証跡がある | 組織利用で別確認が必要なら、自己点検だけで公開せず正式な確認者へ回す |

## 成立する別解・ツール利用不可時の紙上例

### 成立する別解

- AI画像を使わず、文字と単純な図形だけでチラシを作る。
- 権利条件を確認できる自社制作素材または許諾済み素材を使う。
- チラシ案を修正せず全体を不採用とし、一から作り直す。
- ChatGPTを使わず、人が架空設定から原稿を作る。
- Canvaを使わず、組織が承認したプレゼンテーションソフトで非公開下書きを作る。

### 紙上例

1. A4用紙へ、画像、見出し、本文、注意書きの枠を描きます。
2. このページの原稿候補から、元設定にない事実へ赤線を引きます。
3. Canva AI用プロンプトを紙へ書き、人物・文字・ロゴを含めない抽象画像の枠を自分で描きます。
4. 入力、生成、編集、公開前のリスクカードを配置します。
5. 作成例を閉じ、類似、素材条件、誤認、偏り、共有、承認を自分で再確認します。
6. 非公開、修正、差替え、利用中止、専門家相談の判断を記録します。

紙上でも、制作過程と公開前判断を記録し、人間が停止できれば同じ学習成果になります。

## 危険な状態

- 実在人物、作品、キャラクター、ブランド、ロゴを練習へ持ち込んでいる
- 「AI生成」「商用利用可」「編集済み」「類似検索で一致なし」の1点だけで安全と判断している
- AIが追加した実績、推薦、効果、料金、統計を根拠なく残している
- 素材の条件や個別の法的論点が不明なまま公開しようとしている

一つでも当てはまる場合は公開せず、削除、差替え、利用中止、正式窓口・専門家への確認のいずれかを選びます。

## 再挑戦

1. 成果物例との差から1点だけ選び、修正理由を記録します。
2. 入力、生成、編集、公開前の4段階を最初から再確認します。
3. `現時点で何が確認できないため公開を止めるか`を1文で書きます。
4. 自己点検は公開許可や法的判断ではありません。個別案件は担当部署や専門家へつなぎます。
