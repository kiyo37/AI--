# 自己点検ガイド

このフォルダーには、章と演習を終えた後に使う確認例があります。採点や合否判定には使いません。自分の成果物を先に作り、元資料との照合と1点以上の修正を行うために使います。

自己点検や成果物例はAIの実操作の代わりにはなりません。承認済み対話AIを利用できない場合は、環境を準備できるまで対応する章・演習を未完了として停止します。

> **開くタイミング**：演習中に迷ったときは、まず演習本文の「段階ヒント」を使います。自己点検ガイドは、自力課題と元資料照合を終えてから開いてください。

## 自己点検の手順

1. 自分の成果物を保存する。
2. 演習の元資料へ戻り、事実、数字、担当、期限、版、例外を照合する。
3. 対応する自己点検ガイドを開く。
4. 文章が同じかではなく、根拠と安全条件がそろっているかを比べる。
5. 異なる箇所を「誤り」「成立する別解」「未確認」に分ける。
6. 最低1点を修正し、修正理由を成果物へ残す。
7. 完了条件と停止条件を確認して次へ進む。

AI出力もこのガイドも、業務上の最終判断を代行しません。法律、個人情報、著作権、医療、金融、人事などの個別判断は、最新の公式情報と担当者・専門家へ確認してください。

## 判断に迷ったとき

| 状況 | 行動 |
|---|---|
| ガイドと表現が違う | 根拠が一致し、安全条件を満たすなら別解として理由を残す |
| 元資料にない情報がある | 削除するか「要確認」へ直す |
| 数字や担当が一致しない | 元資料を優先し、どこを直したか記録する |
| 入力可否や権利が分からない | 入力・公開・送信を止め、個人学習では扱わず、組織利用では正式窓口へ相談する |
| 自動送信や本番書込みが含まれる | 実行せず、紙上設計または閉じた架空環境へ戻る |

## 更新するときの確認

- [ ] 演習の架空データ、手順、完成条件と一致している
- [ ] 唯一の文章表現を正解にしていない
- [ ] 元資料で確認できる根拠を示している
- [ ] 実在の機密情報、個人情報、認証情報を含まない
- [ ] AI出力をそのまま採用していない
- [ ] 法律・医療・金融等を断定していない
- [ ] 製品情報に公式情報と確認日がある
- [ ] 自力課題の前に答えを見せるリンクになっていない
