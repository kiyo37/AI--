# 学習進捗シート

このファイルは公開リポジトリ内で直接編集しません。リポジトリ外の`ai-learning-work/`または組織指定の非公開保存先へ、`learning_progress.md`としてコピーします。

> [!CAUTION]
> 氏名、会社名、顧客名、案件名、実在データ、社内URL、AIへの実際の業務入力・出力は記録しません。成果物の保存先にも個人名や実在案件名を使わないでください。

学習順序やファイルへのリンクは、公開教材側の[START_HERE](START_HERE.md)だけを基準にします。このシートを別フォルダーへコピーした後は、リンクではなく元のGitHubページからSTART_HEREを開きます。

## 1. 開始時の記録

### 学習経路

- [ ] 個人学習
- [ ] 組織利用

### AI環境の開始条件

- [ ] 利用条件を確認した対話AI、または組織が承認した対話AIへログインできる
- [ ] 教材の完全な架空データを使って、送信と応答確認ができる
- [ ] AIを利用できない場合は、演習を未着手または停止中として環境準備へ戻る

### 目指す完了水準

- [ ] 基礎・実務活用（導入＋第01〜07章＋成果物作成の演習1つ以上＋設計・リスクの演習1つ以上＋第10章）
- [ ] 全編（上記＋第08・09章）

### 開始前チェック

- [ ] 架空データだけを使う
- [ ] 公開リポジトリの外に保存する
- [ ] 外部送信、公開、書込み、削除、支払、権限変更を実行しない
- [ ] 入力・共有の可否が分からない場合の停止方法を説明できる

## 2. 状態の意味

| 状態 | 意味 |
|---|---|
| 未着手 | まだ開始していない |
| 作業中 | 説明または演習を進めている |

| 再確認 | 修正後にもう一度確認する必要がある |

## 5. 各段階の完了確認

- [ ] 承認済み対話AIへ自分で指示し、出力確認、修正指示、再出力の確認を行った
- [ ] 自分で成果物を作って保存してから自己点検を開いた
- [ ] 元資料・規程・公式情報へ戻って確認した
- [ ] AIの作り足し、不明点、未確認事項を区別した
- [ ] 成果物例との違いの理由を書いた
- [ ] 一か所以上を修正して元資料へ再照合した
- [ ] 実務で使う場合の停止条件、人間確認、相談先を説明できる

対話AIを利用できない場合はこの完了確認を付けず、状態を「停止中」として環境準備へ戻ります。
