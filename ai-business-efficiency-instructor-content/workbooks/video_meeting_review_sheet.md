# 学習用：テレビ会議議事録レビューシート

> [!TIP]
> 横長の表はGitHubでは横へスクロールします。`No.`または`根拠時刻`を共通キーに、`主張・問題の種類`と`影響・修正`を分けて確認してください。

このシートは、Zoom・Microsoft Teamsなどのテレビ会議から得た**未確認の自動文字起こし**を、人が確認した議事録へ変える手順を記録するためのものです。Markdownへ入力するか、印刷して使います。

基本演習では、[完全架空の自動文字起こし](../sample-data/video_meeting_transcript.md)と[人間確認カード](../sample-data/video_meeting_verification_notes.md)だけを使います。実在する会議、顧客、人物、会議URL、録画リンクを書かないでください。

## 0. 使用方法

| 利用できる環境 | このシートの使い方 |
|---|---|
| 承認済み対話AI、WordとExcelの両方 | AIの初回草案はチャット画面で確認し、このシートには問題の要約だけを記録する。最終議事録とタスク一覧をWord・Excelへ保存する |
| WordまたはExcelのどちらか一方でも利用不可 | 最終議事録とタスク一覧の両方を、このシートの「4」「5」へ書き、1つのMarkdownファイルとして保存する |
| AIを利用できない | [保存済みAI議事録（問題例）](../sample-outputs/video_meeting_ai_minutes_problem.md)を手で修正する |
| PCを利用できない | 教材から印刷した文字起こし、確認カード、問題例、このシートへ手書きする |

**時刻は発言を探す位置であり、正しさの証明ではありません。** 人間確認カードと食い違う場合は、カードを優先します。

## 4. Officeを利用できない場合の最終議事録

WordとExcelの両方を利用できる場合は、自分または組織が決めたWordファイルへ同じ構成で作り、この欄には保存先だけを書いても構いません。どちらか一方でも利用できない場合は、この「4」と次の「5」を同じMarkdownファイルへ残します。

```markdown
# 架空オンライン問い合わせ業務改善会議 議事録

## 会議情報
- 開催日：
- 参加者の役割：
- 会議の位置付け：

## 3行要約
- {要約1}
- {要約2}
- {要約3}

## 決定事項
1. {決定1}
2. {決定2}
3. {決定3}

## タスク
（「5」のタスク一覧を参照）

## 未決事項
1. {未決1}
2. {未決2}
3. {未決3}

## 要確認・出典位置
- {確認内容と根拠位置}
```

## 5. Excelへ貼り付ける最終タスク一覧

**TSV（タブ区切り）**とは、列と列の間をタブという区切り文字で分けたテキストです。Excelへ貼り付けたときに列へ分けやすくなります。

次のコードブロックをコピーし、`{}`内を人間確認済みの内容へ置き換えます。項目の間はタブです。行は期限の早い順にします。

```tsv
タスク	担当	期限	根拠時刻	人間確認
{タスク1}	{担当1}	{YYYY-MM-DD}	{00:00:00}	{確認方法}
{タスク2}	{担当2}	{YYYY-MM-DD}	{00:00:00}	{確認方法}
{タスク3}	{担当3}	{YYYY-MM-DD}	{00:00:00}	{確認方法}
```

WordとExcelの両方を利用できる場合は、Excelへ貼り付けた後に5列へ分かれたことを確認します。1列になった場合は元に戻し、公式手順で確認したタブ区切りの取り込み方法を使います。解決できない場合や、Word・Excelのどちらか一方でも利用できない場合は、次のMarkdown表を「4」の議事録と同じファイルへ残します。自己判断で追加アプリや拡張機能をインストールしません。

## 6. 共有・公開前の停止条件

次のうち一つでも`はい`または`不明`なら、送信・共有・公開・自動登録を停止し、会議責任者または組織の相談先へ確認します。基本演習では、確認が終わっても外部共有しません。

| 停止条件 | `いいえ`・`はい`・`不明` | 停止後の相談先・行動 |
|---|---|---|
| 実在する個人情報、顧客情報、機密情報が含まれる |  |  |
| 数字、否定、決定、話者、担当、期限に未確認箇所がある |  |  |
| 文字起こし同士、または正式メモと内容が食い違う |  |  |
| 未決事項を決定や確定タスクとして書いている |  |  |
| 会議責任者など必要な承認を得ていない |  |  |
| 閲覧者、共有範囲、ダウンロード可否が分からない |  |  |
| 録画・文字起こし・AI処理の目的、保持期間、削除方法が分からない |  |  |
| 法務・個人情報・情報セキュリティの専門確認が必要である |  |  |

## 7. 保存と終了処理

- [ ] 最終版だけを自分で決めた保存先（組織利用では指定保存先）へ保存した
- [ ] Word議事録とExcelタスク一覧の内容が一致している
- [ ] AIの初回草案を完成品として保存していない
- [ ] AIチャット、録画、文字起こしの共有リンクを作成していない
- [ ] 不要なダウンロードやローカルコピーを残していない
- [ ] 組織ルールに従い、共有範囲、アクセス権、保持・削除設定を確認した
- [ ] 共有PCの場合は、ファイルを閉じてサインアウトした

削除してよいか不明なファイルを自己判断で削除しません。保持・削除の責任者へ確認します。
