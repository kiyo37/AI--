# GitHubで教材を見る方法

## 目的

このガイドは、GitHubアカウントやGitコマンドを使わずに教材を読み、演習成果物を誤って公開しないためのものです。

## ブラウザーで読む

1. 公開された教材リポジトリのURLをブラウザーで開きます。
2. ルートの`README.md`から「学習を始める」を選びます。
3. `START_HERE.md`の順序に沿って、ページ内の相対リンクで移動します。
4. READMEに表示された最新版のReleaseまたはタグと、内容確認日を確認します。
5. ワークブックは、このリポジトリの外にある自分の学習用フォルダーへコピーします。組織利用では指定保存先を使います。

公開リポジトリは通常、閲覧だけならGitHubアカウントを必要としません。教材を読むためだけに、個人情報を含むプロフィールを作成したり、リポジトリをForkしたりする必要はありません。

## Gitを使わず教材一式を保存する

1. READMEに記載された正規リポジトリURLと一致することを確認します。検索広告、転載サイト、短縮URLからダウンロードしません。
2. 安定版を使う場合はGitHubの`Releases`から指定版を開き、配布されたZIPを選びます。Releaseがない場合や最新版を確認したい場合は、リポジトリの`Code`から`Download ZIP`を選びます。
3. ダウンロードしたZIPを、個人学習では自分が管理する場所、組織利用では指定場所へ保存します。
4. ZIPを展開し、教材フォルダー内の`README.md`を開きます。
5. 演習成果物用には、展開した教材フォルダーの**外**に別フォルダーを作ります。教材フォルダー内へ自分の回答、AI出力、実務情報を保存しません。

`main`から取得する`Download ZIP`の内容は更新され得ます。同じ内容を後から参照したい場合は、READMEで案内されたReleaseまたはタグの版を選び、版番号を記録してください。GitHubの画面名、ボタン位置、ZIPの表示方法は変わる可能性があるため、見つからない場合はGitHubの最新公式ヘルプを確認します。

## 公開場所へ投稿しないもの

GitHubのIssue、Pull Request、Discussion、コメント、コミット、画像添付へ、次を投稿しません。

- 顧客メール、会議メモ、社内文書、未公開数値
- 氏名、メールアドレス、社員番号などの個人情報
- パスワード、APIキー、秘密鍵、認証コード
- 社内URL、システム構成、脆弱性、契約情報
- AIへ入力した業務データやAI出力
- 自分や所属組織の業務を具体的に特定できる演習メモ

教材の誤記を報告する場合も、収録された架空例だけを使います。秘密情報・個人情報の混入を見つけた場合は公開Issueへ転載せず、リポジトリの`SECURITY.md`に記載された非公開の報告方法を使います。

## 成果物の保存

- 個人学習では、公開共有されていない自分の学習用フォルダーを使います。
- 組織で学ぶ場合は、組織が指定したローカルフォルダー、社内ストレージ、学習管理システムだけを使います。
- クローンまたはZIP展開した教材フォルダー内へ、自分の回答、AI出力、実データ、実務成果物を保存・コミットしません。
- ファイル名にも顧客名、個人名、案件名を含めません。
- 終了時は[学習終了時チェックリスト](course_closeout_checklist.md)を使います。

## Gitコマンドを使う場合だけ

Gitをすでに使える人が、教材だけを取得する任意手順です。コマンドが分からない場合はブラウザー閲覧を続けます。

```powershell
git clone {公開リポジトリのURL}
```

後日更新する場合は、作業中の変更がないことを確認してから実行します。

```powershell
git pull --ff-only
```

認証を求められた、手元の変更がある、演習成果物を教材フォルダーへ保存した場合は中断します。演習成果物をコミットまたはpushしません。

## 版を確認する

`main`は更新される可能性があります。安定版を再確認するときは、READMEから最新Releaseを開きます。特定の組織学習で指定版がある場合は、そのタグを使います。

## Mermaid図が表示されない場合

GitHubのWebページで閲覧します。ローカルのMarkdownソフトでは、Mermaid図がコードとして表示される場合があります。図の直後にある文章説明だけでも学習内容を確認できます。
