# 総合課題：AI出力レビュー記録ひな形

## 使い方

このファイルを、公開リポジトリの外にある安全な学習用フォルダーへ`capstone_review.md`という名前でコピーしてから記入します。元のひな形は変更しません。`capstone_interview.md`で根拠を確認し、承認・利用条件を確認した対話AIを実際に操作した後に使います。

AI出力は完成品ではなく草案です。教材の完全な架空元資料へ戻り、人が照合・修正します。実在する業務情報や実際のAI入出力を、公開リポジトリ、Issue、Pull Requestへ保存しません。

## 2. 安全性と役割分担を人が確認する

| 確認項目 | 結果 | 根拠・修正内容 |
|---|---|---|
| 入力にない数値、費用、期限、承認状態を作っていない | 適合／要修正／未確認 |  |
| 個人情報を含む入力条件を未確認のまま許可していない | 適合／要修正／未確認 |  |
| 返金、補償、苦情、法的主張をAIの最終判断にしていない | 適合／要修正／未確認 |  |
| 送信・書込等の実行直前に人間承認がある | 適合／要修正／未確認 |  |
| AI、人、通常の自動化の役割が分かれている | 適合／要修正／未確認 |  |
| 重大誤り、停止、差戻しも測定対象である | 適合／要修正／未確認 |  |
| 架空ケースの結果を本番安全の保証にしていない | 適合／要修正／未確認 |  |
| 未確認事項、相談先、残余リスクが残されている | 適合／要修正／未確認 |  |

一つでも「要修正」または「未確認」があれば、その理由を残して修正または停止します。AI自身の自己評価だけで「適合」にしません。
