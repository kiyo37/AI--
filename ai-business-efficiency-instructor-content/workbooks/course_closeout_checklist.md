# 学習終了時チェックリスト

> [!TIP]
> 未回答・引継ぎ記録はGitHubでは横へスクロールします。`質問・事象`ごとに、`暫定対応・確認先`、`次の行動・状態`、`公式根拠・確認日`の順で記入してください。

演習を終えたら自分で確認します。削除やログアウトの要否は、利用したサービスの公式手順、契約、端末の利用形態を優先します。組織利用では組織の規程と正式窓口の指示を優先します。

## 全員が確認すること

- [ ] AIへ入力したのは教材の完全な架空データだけである
- [ ] AI出力を外部送信・公開・実システムへ反映していない
- [ ] GitHubのIssue、Pull Request、Discussion、コメント、コミットへ演習内容を投稿していない
- [ ] 最終成果物を自分で決めた非公開の保存先へ置いた
- [ ] 不要な公開共有リンクを作成していない
- [ ] AIへアップロードした架空ファイルと会話の保存・削除設定を確認した
- [ ] 共有端末を使った場合は、安全にサインアウトした
- [ ] 無断のアプリ、拡張機能、コネクターを追加していない
- [ ] 意図せず無料試用、有料契約、従量課金を開始していない
- [ ] 誤入力や誤共有があれば、秘密値を別資料へ写さず、サービスの正式窓口または組織の事故報告先へ連絡した
- [ ] 未回答事項を「不明」のまま記録し、AIで埋めていない
- [ ] 実務へ移す前の確認者と停止条件を[実務転用シート](work_transfer_sheet.md)へ記入した

## Zoom・Teamsの任意実機を行った場合

- [ ] 録画、文字起こし、AI要約、会議チャットの保存先と閲覧者を確認した
- [ ] 声、表示名、顔、接続情報を「架空データ」と誤認していない
- [ ] ダウンロードした文字起こしや録画を、許可した場所以外へ残していない
- [ ] 共有リンク、アクセス権、保持期限、削除責任を確認した

## 組織で学んだ場合の追加確認

- [ ] 成果物は組織が指定した保存先だけへ保存した
- [ ] 一時共有、閲覧権限、共有リンクを組織の手順で確認した
- [ ] 事故・ヒヤリハットを正式窓口へ引き継いだ
- [ ] 実務での初回試行は、学習とは別の承認・環境で行うと理解した
