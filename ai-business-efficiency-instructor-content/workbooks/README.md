# 記入用ワークブック

このフォルダーには、一人学習で使う記録シートがあります。元ファイルを直接変更せず、自分で決めた安全な場所へコピーして記入します。組織で学ぶ場合は、組織指定の保存先と保持・削除ルールを優先します。

| 資料 | 用途 |
|---|---|
| [GitHub閲覧ガイド](github_viewing_guide.md) | 教材の閲覧、版の確認、公開場所へ投稿しない方法 |
| [初回演習ワークシート](beginner_minutes_worksheet.md) | 架空会議メモとAI草案を照合する |
| [テレビ会議議事録の照合シート](video_meeting_review_sheet.md) | 文字起こしの誤認識と作り足しを記録する |
| [問い合わせ月次報告レビューシート](inquiry_monthly_review_sheet.md) | 明細、集計値、報告表現、停止条件を確認する |
| [業務マニュアル紙上実行シート](manual_usability_review_sheet.md) | 自分で役割を変え、4つの架空ケースから手順書を改訂する |
| [プロンプト受入テスト記録](prompt_acceptance_test_record.md) | 同じケースでv1・v2を比較する |
| [業務ヒアリング・改善提案記録](business_interview_record_sheet.md) | 質問、Before／After、安全な試行案を記録する |
| [実務転用シート](work_transfer_sheet.md) | 実データを書かず、自分の業務を一般化して試行案を作る |
| [学習終了時チェックリスト](course_closeout_checklist.md) | 共有、保存、ログイン、試用契約、未回答事項を確認する |

最初に[学習スタートガイド](../START_HERE.md)を確認してください。自己点検用の確認例は、自力課題を終えた後に[self-check](../self-check/README.md)から開きます。
