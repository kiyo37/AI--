# 総合課題：業務ヒアリング記録ひな形

## 使い方

このファイルを、公開リポジトリの外にある安全な学習用フォルダーへ`capstone_interview.md`という名前でコピーしてから記入します。元のひな形は変更しません。組織で学ぶ場合は、組織指定の保存先、保持期間、削除方法を優先します。

記入するのは、第10章で指定された完全な架空情報だけです。実在する会社名、個人名、顧客情報、社内文書、内部URL、未公開数値、認証情報は記入したりAIへ入力したりしません。

この記録だけでは総合課題の完了になりません。承認・利用条件を確認した対話AIを実際に操作し、`capstone_proposal.md`と`capstone_review.md`も完成させます。

## 0. 開始前の確認

| 項目 | 記入欄 |
|---|---|
| 学習経路 | 個人学習／組織利用 |
| 使用する対話AI |  |
| 利用条件・組織承認の確認 | 確認済み／未確認 |
| 使用する情報 | 教材の完全な架空情報だけ |
| 保存先 |  |
| 実施日 |  |

次のいずれかに当てはまる場合は入力せず、総合課題を未完了のまま停止します。

- 承認・利用条件を確認した対話AIを利用できない
- 実在情報と架空情報を安全に分けられない
- アカウント、データ設定、保存先を確認できない
- 段階開示カードにない回答を推測し、確定事項として記入・入力しようとしている

保存済みAI出力を読むだけでは、AIの実操作の代わりになりません。
