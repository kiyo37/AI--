# NotebookLMの準備ガイド

最終確認日：2026年8月2日

このガイドは、[08 RAGとナレッジマネジメント](../08_rag_and_knowledge_management.md)の基本ハンズオンを安全に始めるためのものです。NotebookLMの画面、機能、利用条件、データの扱いは変わる可能性があるため、利用前に末尾の公式情報を再確認してください。

組織利用では、このリポジトリにある完全な架空資料だけを使用します。実際の社内文書を使うPoCは教材演習中に行わず、教材演習後に別の承認手続と検証環境で実施します。

## 1. この演習で行うこと

完全な架空資料をNotebookLMへ追加し、質問への回答と引用箇所を原文で照合します。社内RAGの本番導入、権限連携、正確性を保証する演習ではありません。

## 2. ブラウザ・インストール・アカウント

| 項目 | 本教材での扱い |
|---|---|
| 利用方法 | パソコンのブラウザから公式サイトを開く |
| インストール | 基本演習ではデスクトップアプリやブラウザ拡張機能をインストールしない |
| アカウント | サインイン済みの個人Googleアカウント、または組織が利用を許可した職場・学校用Googleアカウントが必要 |
| 組織アカウント | 管理者によるサービスの有効化、ライセンス、機能、データ保護条件が組織設定で異なるため、管理者へ確認する |
| ブラウザ条件 | 対応ブラウザ、ネットワーク、提供地域などを最新の公式ヘルプで確認する |

企業端末へアプリや拡張機能を無断で追加しません。モバイルアプリが利用可能でも、本教材の基本手順はパソコンのブラウザを前提にします。

## 3. 利用環境を選ぶ

| 状況 | 使用してよい環境 | 入力できる資料 |
|---|---|---|
| 個人学習 | 本人が管理し、規約・データ条件を確認した個人アカウント | 教材の完全な架空資料、または権利と公開範囲を確認した公開資料 |
| 組織利用 | 管理者が発行・許可した業務アカウントと指定URL | 教材として一から作った完全な架空資料だけ |
| 許可が不明 | 使用しない | アップロードしない |
| AIなし・アカウントを準備できない | 紙上代替へ切り替える | [RAG質問・資料カード](../sample-data/rag_question_cards.md)と[保存済み回答](../sample-outputs/notebooklm_saved_answers.md) |

個人アカウントと組織アカウントでは、利用規約やデータ保護の条件が異なる場合があります。「Googleのサービスだから社内資料を入れてよい」と自己判断しません。

## 4. 登録・サインイン前の確認

- [ ] 組織利用では、業務責任者と管理者がNotebookLMの利用を承認している
- [ ] 組織利用では、使用するアカウント、URL、利用可能機能が正式な利用案内または管理ポータルに記録されている
- [ ] 個人学習では、本人が利用規約、プライバシー、料金が生じる条件を確認した
- [ ] 教材用の完全な架空資料を用意した
- [ ] 個人情報、機密情報、パスワード、APIキー、未公開資料を除いた
- [ ] 投影時にアカウント名、履歴、通知、他のノートブックが映らないようにした
- [ ] 利用できない場合の紙上資料と保存済み回答例を用意した

組織利用では、承認前に個人アカウントの新規作成や個人メールでの登録を求めません。自己サービス登録が可能に見えても、組織の手順を優先します。

## 5. アカウントを保護する

1. 組織アカウントでは、管理者が指定したSSO（組織の共通認証）とMFA（パスワード以外の確認も使う多要素認証）を使用します。
2. 個人Googleアカウントでは、[Google公式の2段階認証ガイド](https://support.google.com/accounts/answer/185839)を確認し、利用可能なら有効にします。
3. 確認コードやバックアップコードを正式窓口、チャット、教材、共有画面へ載せません。
4. 共用端末ではログイン状態を残さず、ブラウザへのパスワード保存は組織ルールに従います。

## 6. 架空データで動作確認する

### 準備する資料

次の完全な架空資料を使います。実在する会社名、人物名、メールアドレス、顧客情報は含まれていません。

- [現行版の架空研修運営規程](../sample-data/rag_training_rules_current.md)
- [旧版の架空研修運営規程](../sample-data/rag_training_rules_old.md)
- [RAG質問・資料カード](../sample-data/rag_question_cards.md)

```text
文書ID：TRAINING-FAQ-001
名称：架空AI研修 申込FAQ
版：第2版
施行日：2026年7月1日

申込期限は開催日の5営業日前です。
定員に達した場合は、期限前でも受付を終了します。
例外の判断は架空研修事務局が行います。
```

### 操作確認

1. [NotebookLM公式サイト](https://notebooklm.google/)を、承認済みアカウントで開きます。
2. 新しいノートブックを作り、上記の現行版と旧版の架空資料だけをソースとして追加します。
3. 「申込期限を、根拠の該当箇所とともに示してください」と質問します。
4. 表示された引用を開き、回答と原文が一致するか人が確認します。
5. 「受講料はいくらですか」のように資料にない質問をし、推測や作り話がないか確認します。
6. 文書名、版、質問、回答、原文照合の結果、見つけた問題を演習記録へ残します。

引用表示は正しさの保証ではありません。回答の数字、否定、例外、対象者、版を必ず原文で確認します。

## 7. 利用できない場合の紙上代替

登録、サインイン、アップロードを行わず、次の手順で学びます。

1. [RAG質問・資料カード](../sample-data/rag_question_cards.md)を開きます。
2. 質問に関係するカードを選びます。
3. 「回答、根拠、適用対象、注意、相談先」の欄を埋めます。
4. 資料にない質問では「回答できない」と書きます。
5. [NotebookLM演習の保存済み回答](../sample-outputs/notebooklm_saved_answers.md)と比較し、人が原文確認する箇所を記録します。

この代替でも、検索、根拠提示、未回答、人間レビューというRAGの基本を学べます。

## 8. 中止・相談する条件

- 組織の利用許可、アカウント種別、アップロード可否が不明
- 実在する個人情報、機密情報、認証情報が資料に含まれている
- 共有範囲、保存、削除、データの扱いを確認できない
- 回答と引用が一致しないのに業務へ使おうとしている
- 法律、著作権、個人情報、医療、金融などの個別判断に使おうとしている

不明な場合は入力を止め、組織の管理者・情報セキュリティ・法務・個人情報保護担当、必要に応じて専門家へ確認します。

## 9. 演習終了時の後片付け

- [ ] ノートブックとソースの共有リンク、共同編集者、公開設定を解除した
- [ ] 演習用ノートブック、アップロード、回答、ダウンロードを、組織の保存・削除手順どおりに扱った
- [ ] 共用・貸与端末からサインアウトした
- [ ] 本演習のために始めた試用、有料機能、自動更新がないか本人または契約責任者が確認した
- [ ] 誤共有、誤入力、権限外表示、意図しない課金等の事故や疑いを確認した

事故の疑いがある場合は、秘密値や個人情報をスクリーンショット・事故票へ複製せず、操作を止めて正式窓口へ報告します。
