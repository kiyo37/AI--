# Perplexity演習環境セットアップ

最終確認日：2026-08-02

## 1. この文書の目的

この文書は、[第05章 ハルシネーションとファクトチェック](../05_hallucination_and_fact_checking.md)の演習でPerplexityを安全に使うための準備手順です。Perplexityは、Web上の情報を探し、回答と出典候補を表示するAI検索サービスです。

製品の画面、プラン、利用上限、保存、学習利用、管理機能は変わる可能性があります。利用時は最新の公式情報、契約、自組織の規程、管理設定を優先してください。AIが示した出典は必ず人間が開き、公式原文の該当箇所を確認します。

> この演習に機密情報、個人情報、認証情報、未公開情報を入力しません。法律、著作権、個人情報、医療、金融などの個別判断は、担当部門または専門家へ確認してください。

## 2. 先に選ぶ利用方法

| 状況 | 選ぶ方法 | アカウント登録 |
|---|---|---|
| 個人学習で、自分の意思でサービスを使う | 個人アカウントまたは当日利用できる未ログイン範囲を確認 | 利用条件を理解して本人が選ぶ |
| 組織利用で承認済み環境がある | 組織が発行・招待したアカウントを使用 | 管理者の手順に従う |
| 組織利用で未承認、登録禁止、審査中 | Perplexity演習は実施しない | 個人登録をせず、コア対話AIの実操作を伴う第05章の基本演習を行う |

組織利用では、私用メールアドレス、私物のGoogle・Appleアカウント、個人契約の有料プランへ切り替えません。承認済みアカウントがなければPerplexityの任意演習を飛ばし、承認済みのコア対話AIを使う学習へ戻ります。

## 3. ブラウザとインストール

この教材ではPerplexityのWebアプリを使うため、デスクトップアプリやブラウザ拡張機能の追加インストールは不要です。

対応ブラウザと必要条件は変わります。利用前に[Perplexityウェブアプリ対応ブラウザ](https://www.perplexity.ai/help-center/ja/articles/11502647-perplexity%E3%82%A6%E3%83%96%E3%82%A2%E3%83%97%E3%83%AA%E5%AF%BE%E5%BF%9C%E3%83%96%E3%83%A9%E3%82%A6%E3%82%B6)を開き、現在の条件を確認します。組織利用では管理対象ブラウザを使い、固定のバージョン番号を暗記しません。

アクセス先は[Perplexity](https://www.perplexity.ai/)です。偽のログイン画面を避けるため、リンク先のドメインが`perplexity.ai`であることを自分で確認します。組織利用では指定URLも照合します。

## 4. 個人学習での準備

### 4.1 アカウントを使う場合

- 利用規約とプライバシー情報を読み、自分の意思で登録する
- 学習用に管理できるメールアドレスを使い、共有アカウントを作らない
- GoogleやApple等の連携ログインを使う場合は、連携元アカウントの共有情報も確認する
- 強く固有のパスワードを使い、他サービスと使い回さない
- ログインに使うメール、Google、Apple等で多要素認証を有効にする

**多要素認証（MFA）**とは、パスワードに加え、認証アプリや端末確認など別の要素でも本人を確かめる仕組みです。Perplexity側の個人向け認証画面は変わり得るため、当日のアカウント設定と公式ヘルプを確認します。

### 4.2 データ設定を確認する

[Account & Settings](https://www.perplexity.ai/help-center/en/articles/10352990-account-settings)と[Data Collection at Perplexity](https://www.perplexity.ai/help-center/en/articles/11564572-data-collection-at-perplexity)を参照し、少なくとも次を確認します。

| 設定・機能 | 演習時の扱い | 注意 |
|---|---|---|
| AI data retention / AI Data Usage | 自分の希望と利用目的に合わせて確認し、不要ならオフにする | 公式説明では個人向けプランで既定が有効の場合がある。変更前に収集されたデータへ遡及しないとされる |
| 履歴・Incognito | 保存が不要ならIncognito等の現在の仕様を確認 | 履歴に残さない機能は、機密情報を入力してよい許可ではない |
| Personalization | 職業、会社名、所在地等を不要に登録しない | 回答の個人化に使われる情報を最小化する |
| Connectors | 演習では接続しない | Google Drive等を接続すると対象データと権限が広がる |
| 共有 | 回答リンクを公開しない | この教材の演習では外部共有しない |
| ファイル添付 | 演習では使わない | ローカルファイル名や文書内情報も入力に含まれる |

## 5. 組織利用での準備

### 5.1 組織管理者が確認すること

- 利用可能なプラン、対象部署、利用者、費用負担
- アカウントの発行・招待・削除方法
- SSO、MFA、退職・異動時の停止方法
- AI学習利用、保存期間、削除、監査ログ
- ファイル添付、共有、外部公開、コネクターの許可範囲
- 利用モデルや外部モデル提供者に関する設定・契約
- インシデント窓口と、誤入力時の証跡保全手順

**SSO（シングルサインオン）**とは、組織の共通ログイン基盤でサービスへ入る仕組みです。Perplexityの公式ヘルプでは、有料組織向けのSSO設定が案内されています。企業では[SSO Integration: Getting Started](https://www.perplexity.ai/help-center/en/articles/11200832-sso-integration-getting-started)を確認し、組織のID管理基盤側でMFAを適用します。提供範囲は契約と管理画面で再確認してください。

### 5.2 データ保護をプラン名だけで決めない

2026-08-02時点の公式説明では、EnterpriseのデータはAIモデル学習に使わないと案内されています。一方で、保存、削除、ファイル、共有、接続先等は別の確認事項です。[Enterprise Organization Permissions](https://www.perplexity.ai/help-center/en/articles/12053065-enterprise-organization-permissions)も参照し、実際の契約と管理設定を確認します。

「法人向けだから何を入力してもよい」とは説明しません。自社の情報分類と目的に照らし、演習では公開情報と完全な架空データだけを使います。

## 6. 架空データでの動作確認

次の順で、検索、出典表示、公式原文への移動だけを確認します。

1. 新しいスレッドを開きます。
2. 次の文を入力します。

```text
これは架空の社内研修の動作確認です。Perplexity Webアプリの対応ブラウザについて、
Perplexity公式ヘルプだけを出典にし、ページ名、URL、更新日を示してください。
確認できない情報は推測しないでください。
```

3. 回答内の出典を開き、ドメインが `perplexity.ai` か確認します。
4. 公式ページ本文で、回答と同じ対象、日付、条件が書かれている箇所を探します。
5. 回答と原文に違いがあれば、「誤り」または「不明」と記録します。
6. スレッドを外部共有せず、組織の手順に従って終了します。

動作確認で架空という言葉を入れても、サービス側のデータ取扱いは変わりません。入力内容そのものを安全な公開情報と架空情報に限定することが重要です。

## 7. Perplexityを利用できない場合

| 利用できない理由 | 対応 | 継続する学習 |
|---|---|---|
| 個人登録を希望しない | Perplexityは使わず、本人が条件を確認したコア対話AIを使う | 第05章の基本演習でAI出力と公式原文を照合する |
| 組織で未承認 | Perplexityは使わず、組織承認済みの対話AIへ戻る | 組織ルールの範囲でAIの実操作を続ける |
| ネットワークで遮断 | Perplexityの任意演習を停止する | 復旧後に再開するか、第05章のコア対話AI演習だけを行う |
| 障害・画面変更 | 復旧を待つか、承認済みの別の検索支援AIがあれば使う | コア対話AIによる生成と人間の出典確認は続ける |

教材の固定例は、誤り分析や画面トラブルの切り分けにだけ使えます。固定例の確認だけではAIの実操作の代替にならず、Perplexity演習を完了したことにはしません。

## 8. 利用者の開始前確認

- [ ] 公式ヘルプを開き、画面と対応ブラウザを再確認した
- [ ] 個人学習では本人管理アカウント、組織利用では承認済みアカウントとデータ設定を確認した
- [ ] Perplexityへ登録しない場合も、承認済み対話AIを実操作し、固定例は実操作後の比較だけに使うと確認した
- [ ] 完全な架空プロンプトで動作確認した
- [ ] 検索結果から公式原文を開く操作を確認した
- [ ] 出典が変わった場合に備え、URL、確認日、該当見出しを記録した
- [ ] 法律、医療、金融等の個別判断はAIだけで確定せず、必要な専門家へ相談すると確認した
