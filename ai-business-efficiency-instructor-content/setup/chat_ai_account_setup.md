# 対話AIアカウント準備ガイド

## 1. このガイドの目的

対話AIを基本演習に使える状態へ、安全に準備します。ChatGPT、Claude、Geminiなどは選択肢であり、特定製品の登録は必須ではありません。個人学習、組織利用、AIなしのいずれでも、[クイックスタート](participant_quickstart.md)を完了できます。

> 画面名、登録方法、利用可能な機能、年齢・地域条件、料金、データ設定は変更されます。本書の確認日は**2026年8月2日**です。実施直前に、必ず各社の最新公式情報と組織のルールを確認してください。

## 2. 最初に決めること

| 確認項目 | 組織利用 | 個人学習 | AIなし |
|---|---|---|---|
| 登録の判断者 | 組織の管理者、情報システム、セキュリティ等 | 本人 | 登録しない |
| 使用アカウント | 管理者が発行・招待した業務用アカウント | 本人が管理する個人アカウント | 不要 |
| 入力できる情報 | 教材内の架空データ | 教材内の架空データ。勤務先や顧客の情報は入力しない | [保存済み問題出力](../sample-outputs/beginner_minutes_saved_output.md)を確認する |
| 完了方法 | 対話AIの出力を元資料と照合する | 対話AIの出力を元資料と照合する | 保存済み出力を元資料と照合し、手作業で修正する |

企業のメールアドレスを使えることと、業務利用が承認されていることは別です。登録、利用プラン、入力データ、外部連携について、先に組織の承認を得てください。

## 3. インストールは必要か

| 利用方法 | インストール | 注意 |
|---|---|---|
| ブラウザ | 原則不要 | 本教材の基本。組織が許可したブラウザと公式URLを使う |
| デスクトップアプリ | 必須ではない | 組織の端末管理ルールと公式配布元を確認する |
| モバイルアプリ | 必須ではない | 端末紛失、通知への表示、写真・マイク権限を確認する |
| ブラウザ拡張機能 | 基本演習では不要 | 閲覧ページへのアクセス範囲が広い場合があるため、無断導入しない |

検索広告や第三者サイトのログイン画面を使わず、次の公式URLをブックマークします。

- ChatGPT：<https://chatgpt.com/>
- Claude：<https://claude.ai/>
- Gemini：<https://gemini.google.com/>

## 4. 登録・サインイン前の確認

- [ ] 組織で利用する場合、製品・プラン・アカウント種別の承認を得た
- [ ] 管理者発行アカウントを使うか、個人アカウントを使うかを区別した
- [ ] 公式URL、利用規約、プライバシー情報、年齢・地域条件、料金を確認した
- [ ] 回復用メール、認証端末、パスワード管理方法を用意した
- [ ] 入力禁止情報と、誤入力時の連絡先を確認した
- [ ] アプリ連携、ファイルアップロード、共有リンクは初回練習で使わないと決めた

不明な項目があれば登録や入力を進めず、企業では管理者へ、個人では公式サポート情報へ確認します。

## 5. アカウント種別ごとの準備

### 5.1 組織利用

1. 個人プランへ切り替えず、組織の正式な利用案内または管理ポータルで発行済みアカウントを確認します。
2. 管理者が指定したメールアドレス、SSO（Single Sign-On、組織の共通認証）、ブラウザを使います。
3. サインイン後、個人用領域ではなく、指定された組織のワークスペースまたは業務用アカウントであることを確認します。
4. 利用可能なモデル、共有、履歴、ファイル、連携機能は、管理者設定と社内ルールを優先します。
5. 教材演習では完全な架空データだけで動作確認します。匿名化した実データを含む本番データの検証は、教材演習と分離したPoCで別途審査します。

ChatGPT Business・Enterpriseなどの組織用ワークスペース、Claude for Work、Google WorkspaceのGeminiは、個人向けアカウントと管理・データ条件が異なります。製品名だけで安全と判断せず、実際の契約と設定を管理者が確認します。

### 5.2 個人学習

1. 本人が利用条件と費用を確認し、必要な場合だけ個人アカウントを作成します。
2. 他サービスと同じパスワードを使わず、回復方法を設定します。
3. MFAまたは2段階認証を利用できる場合は有効にします。
4. 履歴、モデル改善への利用、接続アプリ、共有の設定を確認します。
5. 勤務先、顧客、学校、家族など第三者の実情報は入力せず、教材の架空データだけを使います。

個人アカウントの設定を変更しても、企業の業務データを入力してよい根拠にはなりません。

## 6. 製品別の確認ポイント

### 6.1 ChatGPT

- ブラウザで <https://chatgpt.com/> を開きます。地域や提供状況によってはサインアウト状態で一部機能を試せる場合がありますが、履歴保存などにはアカウントが必要です。
- 企業利用では、管理者から指定されたワークスペースへの招待・認証方法に従います。個人ワークスペースと組織ワークスペースを取り違えないよう、入力前に現在の領域を確認します。
- 個人利用では、`Settings` の `Data Controls` で会話の取扱設定を確認します。設定名や位置は変わる場合があります。
- `Settings` の `Security` で利用可能なMFA方式を確認し、回復手段も用意します。
- 個人向け設定でモデル改善への利用を無効にしても、機密情報を入力してよいことにはなりません。

### 6.2 Claude

- ブラウザで <https://claude.ai/> を開きます。個人利用では、公式画面が案内するメールまたは対応する認証方法でサインインします。
- 企業利用では、Claude for Workの管理者招待、許可ドメイン、SSO等の組織設定に従います。個人アカウントを業務用の代わりにしません。
- 個人向けと商用プランではデータ取扱条件が異なります。個人利用ではPrivacy SettingsやIncognito等の最新説明を確認し、企業利用では組織の契約・保持・共有設定を確認します。
- Claude固有のMFA手順を推測せず、サインイン元のGoogleアカウント、メール、または企業のID基盤で利用できる保護を公式案内と管理者指示に従って設定します。

### 6.3 Gemini

- ブラウザで <https://gemini.google.com/> を開きます。一部機能をサインインせず使える場合がありますが、地域、端末、機能によって条件が異なります。
- 個人利用では個人Googleアカウント、企業利用では管理者が有効化した対象の仕事用Googleアカウントを使います。
- 個人利用ではGemini Apps Activity、履歴、接続アプリを確認します。仕事用・学校用アカウントでは、これらの設定を管理者が制御する場合があります。
- Googleアカウントの2段階認証と回復方法を設定します。企業では管理者が指定する認証方法を優先します。

## 7. MFAとアカウント保護

**MFA（Multi-Factor Authentication、多要素認証）**は、パスワードに加えて別の方法でも本人確認する仕組みです。

| 確認 | 実施内容 |
|---|---|
| 認証方法 | 組織指定の認証アプリ、パスキー、セキュリティキー等から選ぶ |
| 回復 | 回復用情報やバックアップ方法を安全に保管する |
| 端末 | 共用端末にログイン状態を残さず、離席時に画面をロックする |
| 共有禁止 | ID、パスワード、MFAコード、回復コードを他人と共有しない |
| 異常時 | 不審なログインや誤共有を確認したら、利用を止めて管理者・公式サポートへ連絡する |

企業アカウントでは、利用者が独自設定を変えず、組織のID・端末・条件付きアクセス方針に従います。

## 8. データ設定の確認

| 製品・アカウント | 主に確認する設定 | 判断者 |
|---|---|---|
| ChatGPT個人向け | Data Controls、履歴、モデル改善への利用、共有リンク、接続機能 | 本人。ただし業務利用は不可とされる場合がある |
| ChatGPT組織向け | ワークスペース、利用者、権限、共有、保持、許可機能 | 組織管理者 |
| Claude個人向け | Privacy Settings、モデル改善、履歴、Incognito、連携 | 本人 |
| Claude for Work | メンバー、役割、SSO、保持、共有、連携 | 組織管理者 |
| Gemini個人向け | Gemini Apps Activity、履歴、接続アプリ、共有 | 本人 |
| Gemini仕事・学校用 | サービス有効化、保持、接続アプリ、Workspace権限 | 組織管理者 |

設定を変えた後も、入力禁止情報、利用目的、最小化、人間レビューのルールは残ります。

## 9. 架空データでの動作確認

[共通準備と安全確認](common_preparation.md#7-接続確認)の短い接続確認を、新しいチャットで行います。これはログインと応答だけを確かめる作業であり、完成成果物ではありません。

応答を確認できたら、[クイックスタート](participant_quickstart.md)へ進み、完全な架空会議メモからWord用議事録とExcel用タスク一覧を作ります。接続確認でも実務演習でも、共有リンクの作成や外部送信は行いません。

## 10. 登録・利用できない場合の代替

| 状況 | 代替方法 |
|---|---|
| 組織でアカウントが未発行 | 正式窓口へ申請し、発行までは紙上プロンプトと[保存済み問題出力](../sample-outputs/beginner_minutes_saved_output.md)を使う |
| 製品が地域・年齢・契約条件で使えない | 利用条件を回避せず、利用可能な承認済み製品または紙上演習へ変更 |
| MFA端末を用意できない | 企業では管理者へ相談し、個人では公式の別方式・回復方法を確認。アカウント共有はしない |
| 学習中に障害が発生 | 演習からリンクされた保存済み架空出力を使い、人間レビュー工程を継続 |
| 比較用ツールが足りない | 追加登録せず、教材に収録された同一課題の架空出力を比較する |

## 11. 準備完了チェック

- [ ] 企業用／個人用のどちらかを明確にした
- [ ] 企業利用では管理者の発行・承認を確認した
- [ ] 公式URLを使い、不要なアプリや拡張機能を入れていない
- [ ] MFAまたは組織指定の認証を設定した
- [ ] データ設定、入力禁止情報、誤入力時の連絡先を確認した
- [ ] 架空データで生成し、人が元文と照合した
- [ ] 利用不可・障害時の代替方法を用意した

### 停止条件

- アカウント種別、料金、規約、データ設定、組織の承認が確認できない
- 実在の個人情報、機密情報、認証情報を入力・添付しようとしている
- 意図しない共有、外部アプリ接続、メール送信、公開が有効になっている
- 元資料と照合できない出力を、そのまま保存・送信・重要判断へ使おうとしている

該当したら入力・送信を止め、個人学習ではAIなし経路へ切り替えます。組織利用では秘密情報を別のメモへ複製せず、正式窓口へ確認します。
