## 4. インストールについて

本教材の基本演習は、原則として対応ブラウザから利用します。「AIツールを使う＝必ずパソコンへアプリをインストールする」ではありません。デスクトップアプリ、モバイルアプリ、ブラウザ拡張機能が必要な演習は必須にしません。

アプリや拡張機能を追加する場合は、個人学習では公式配布元を確認し、企業研修ではIT管理者の承認と配布手順に従います。

## 5. 個人学習と企業研修の分岐

| 確認項目 | 個人学習 | 企業研修 |
|---|---|---|
| アカウント | 本人が公式サイトから登録 | 管理者が発行・招待した業務アカウントを使用 |
| メール | 本人が管理するメール | 組織が指定した業務メール |
| 登録許可 | 本人が規約と条件を確認 | 組織の利用ルール、契約、管理者承認を確認 |
| 入力データ | 教材の完全な架空データだけ | 教材の架空データ。実データ利用は別手続 |
| 設定 | セキュリティ・データ設定を本人が確認 | 管理者設定を優先し、利用者が変更しない |
| 利用不可時 | 保存済み出力または紙上演習 | 講師が紙上代替へ切り替える |

## 6. 研修担当者の準備チェック

- [ ] 演習で必須にするツールを最小限に絞った
- [ ] 個人登録と企業アカウントの手順を混同していない
- [ ] 企業受講者へ個人アカウント作成を強制していない
- [ ] 利用規約、データ取扱い、対象地域、契約、管理設定を確認した
- [ ] 登録・ログイン・MFA・ネットワーク制限を事前確認した
- [ ] 架空データと紙上代替を準備した
- [ ] 実メール送信、公開、支払、削除、権限変更を行わない設定にした
- [ ] 公式情報の確認日を研修資料へ記録した

## 7. 更新方針

AIツールの登録方法、名称、画面、料金、提供地域、機能、データ取扱いは変わる可能性があります。各ガイドは画面上のボタン位置を暗記させる資料ではありません。研修前に掲載した公式リンクを開き、最新情報へ更新してください。
