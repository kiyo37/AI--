# 利用環境の準備ガイド

このフォルダーには、演習でツールを開く前の確認手順があります。すべてを読む必要はありません。[共通準備](common_preparation.md)を確認した後、実施する演習に必要なガイドだけを開きます。

## 最初に選ぶ経路

| 状況 | 準備 |
|---|---|
| 個人学習 | 本人が公式サイト、規約、料金、データ設定を確認する。教材の架空データだけを使う |
| 組織利用 | 組織が承認したサービス、アカウント、URL、保存先、相談先を確認する |
| AIなし・未承認・登録不可・障害 | 新規登録や設定変更をせず、[保存済み出力一覧](../sample-outputs/README.md)または紙上経路へ進む |

有料登録、試用開始、アプリや拡張機能のインストールは、教材を完了する条件ではありません。

## 登録・インストールの原則

- ブラウザ利用を基本とし、アプリのインストールを必須にしない
- 個人学習では、本人が管理できるアカウントだけを本人の判断で使用する
- 組織利用では、私物アカウントや個人メールで未承認サービスへ登録しない
- パスワード、MFAコード、APIキーを教材、AI、Issue、画面共有へ載せない
- 料金や試用条件を確認できない画面では先へ進まない
- ファイル添付、Web検索、コネクタ、共有は、演習で必要性と条件を確認した場合だけ使う

## 演習前チェック

- [ ] 個人学習・組織利用・AIなしのどの経路か決めた
- [ ] 使うサービスの正規URLを確認した
- [ ] 入力するのは教材の完全な架空データだけである
- [ ] 保存先と終了時の処理を決めた
- [ ] AIを使えない場合に開く保存済み出力を確認した
- [ ] 外部送信、公開、削除、支払、権限変更を実行しない
- [ ] 分からない場合の停止・相談経路がある

個人学習で相談先がない場合は、課金、登録、外部接続、公開を行わず、AIなし経路へ切り替えれば基本学習を続けられます。
