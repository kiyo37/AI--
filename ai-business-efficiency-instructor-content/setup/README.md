# 利用環境の準備ガイド

このフォルダーには、演習でツールを開く前の確認手順があります。[共通準備](common_preparation.md)を確認した後、実施する演習に必要なガイドだけを開きます。

> **本教材では、承認済みの対話AIを自分で操作することが必須です。** AIを利用できない状態では、セットアップ完了まで学習を一時停止してください。保存済み出力はトラブルの切り分けや誤り分析に使う補助資料であり、AIの実操作の代わりにはなりません。

## 最初に選ぶ経路

| 学習経路 | 準備 |
|---|---|
| 個人学習 | 本人が公式サイト、利用規約、料金、データ設定を確認した対話AIを使う。教材の架空データだけを入力する |
| 組織利用 | 組織が承認した対話AI、アカウント、URL、保存先、相談先を使う |

対話AIは必須ですが、特定の製品、有料登録、アプリや拡張機能のインストールは必須ではありません。ChatGPT、Claude、Gemini、Microsoft Copilotなどから、上の条件を満たすサービスを一つ準備します。

特定の製品を利用できない場合も、承認済みの同等機能があれば置き換えられます。第08章のRAG機能や、第09章の追加実機など任意発展に必要な機能を用意できなければ、その任意部分を飛ばします。必修章で指定されたAI機能を用意できない場合は、代替機能を準備するまでその演習を停止します。

## 登録・インストールの原則

- ブラウザ利用を基本とし、アプリのインストールを必須にしない
- 個人学習では、本人が管理できるアカウントだけを本人の判断で使用する
- 組織利用では、私物アカウントや個人メールで未承認サービスへ登録しない
- パスワード、MFAコード、APIキーを教材、AI、Issue、画面共有へ載せない
- 料金や試用条件を確認できない画面では先へ進まない
- ファイル添付、Web検索、コネクタ、共有は、演習で必要性と条件を確認した場合だけ使う

## 演習前チェック

- [ ] 個人学習・組織利用のどちらの経路か決めた
- [ ] 条件を確認した承認済み対話AIを自分で操作できる
- [ ] 使うサービスの正規URLを確認した
- [ ] 入力するのは教材の完全な架空データだけである
- [ ] 保存先と終了時の処理を決めた
- [ ] 外部送信、公開、削除、支払、権限変更を実行しない
- [ ] 分からない場合の停止・相談経路がある

対話AIへ接続できない、承認がない、アカウントを準備できない場合は、学習を完了扱いにせず、準備が整うまで停止します。個人学習では別の利用可能なAIの公式条件を確認し、組織利用では正式窓口へ相談してください。
