# クイックスタート：会議メモを議事録とタスク一覧にする

このページでは、生成AIを初めて使う人が、完全な架空の会議メモを承認済み対話AIへ入力し、次の実務成果物を作ります。個人学習または組織利用のどちらでも、AIの実操作が必須です。

- WordまたはMarkdownで読める議事録
- Excel、Markdownまたは紙で管理できるタスク一覧

AIに文章を作らせて終わりではありません。**元の会議メモとの照合、AIへの修正指示、使いやすくするための改善、人による最終確認**まで行います。

> **最初に貼り付けるのは、「3. AIへ最初の指示を送る」にあるコードブロック一つだけです。** コードブロックには元の会議メモも含まれています。元メモだけを先に送ったり、実際の会議情報へ書き換えたりしません。対話AIを利用できない場合は[10. AIを使えない場合](#10-aiを使えない場合)を確認し、準備完了後に戻ってください。

## 0. この演習で行う作業

| 順番 | 実際に行うこと | 完了した状態 |
|---:|---|---|
| 1 | 個人学習・組織利用の経路と保存先を確認する | 開始条件と停止条件を説明できる |
| 2 | 新しいチャットを開く | 過去の会話がない入力欄が表示されている |
| 3 | 完成済みプロンプトをAIへ送る | 議事録案とタスク一覧案を確認できる |
| 4 | 元メモとAI出力を照合する | 誤り、抜け、AIによる作り足しを判定できている |
| 5 | 同じチャットでAIへ修正を指示する | 修正版を元メモと再照合している |
| 6 | 指示を一つ改善して再生成する | タスクが期限の早い順に整理されている |
| 7 | 利用できる形式で成果物を仕上げる | Word・Excel、Markdownまたは紙の最終版がある |
| 8 | 外部送信せず安全に終了する | 指定保存先以外へ共有・公開していない |

初回出力をメモ帳へ保存する作業や、練習履歴を別ファイルへ転記する作業は行いません。保存するのは、人が確認した最終成果物だけです。

## 1. 操作を始めてよいか確認する

### 1.1 自分の進め方を確認する

| 状況 | 進め方 |
|---|---|
| 組織からAIと業務用アカウントを指定された | 組織指定のURL・アカウントを使い、[2. 対話AIを開く](#2-対話aiを開く)へ進む |
| 個人学習で、利用条件とデータ設定を自分で確認できる | 完全な架空データだけを使って進む |
| AIが未承認、ログインできない、指定が分からない | 登録や設定変更をせず、[10. AIを使えない場合](#10-aiを使えない場合)を確認して準備完了まで停止する |

組織利用では、個人メールアドレスや私物アカウントを使った新規登録をしません。個人学習でも、料金・規約・データ設定を確認できない場合は登録せず、アプリ、拡張機能、コネクタを安易に追加しません。

### 1.2 利用環境を記録する

個人学習では公式情報で自分が確認した内容を、組織利用では組織の正式な利用案内または管理ポータルで確認した内容を記録します。空欄や不明がある場合はAIを開かず、[10. AIを使えない場合](#10-aiを使えない場合)を確認して準備完了まで停止します。

| 確認項目 | 確認した内容 |
|---|---|
| 使用する対話AI |  |
| 開くURL |  |
| 使用するアカウント（個人／業務） |  |
| 入力してはいけない情報 |  |
| 完成ファイルの保存先 |  |
| 困ったときの相談先 |  |

### 1.3 入力前チェック

次のすべてにチェックできた場合だけ先へ進みます。

- [ ] 個人学習では公式URLと本人管理アカウント、組織利用では指定URLと業務用アカウントを使っている
- [ ] 入力するのは、このページに記載された完全な架空データだけである
- [ ] 実在する氏名、顧客情報、社内情報、パスワード、APIキーを追加していない
- [ ] ファイル添付、Web検索、外部アプリ接続、共有リンク作成を使わない
- [ ] AI出力をメール、チャット、予定表、業務システムへ送信・登録しない
- [ ] AIは草案を作り、事実と利用可否は人が確認すると理解している

## 2. 対話AIを開く

1. 業務情報が表示されているメールや文書を保存し、画面に表示されない状態にします。
2. 個人学習では確認済みの公式URL、組織利用では指定されたURLをブラウザで開きます。
3. 画面右上などのアカウント表示を確認します。
4. 事前に確認した本人管理アカウントまたは組織指定アカウントと一致していれば先へ進みます。
5. 「新しいチャット」「新しい会話」などをクリックします。
6. 過去の会話が表示されていない、空の入力欄を確認します。
7. ファイル添付、Web検索、画像生成、共有などは選びません。

製品によってボタン名や場所は変わります。公式案内または組織の案内と違う場合は、設定を推測で変えず操作を停止します。個人学習では別の利用可能な対話AIを確認し、組織利用では正式窓口へ確認します。

## 3. AIへ最初の指示を送る

### 操作1：コピーする

次のコードブロック内にある、`あなたは`から`以上を守って作成してください。`までが、AIへ最初に送る全文です。

1. コードブロック内を選択します。
2. `Ctrl+C`を押します。
3. 説明文やこの見出しをコピーしていないことを確認します。

```text
あなたは、社内会議の記録を整理するアシスタントです。

目的：架空の会議メモから、Wordに貼り付ける議事録と、Excelに貼り付けるタスク一覧を作る。
読者：会議の参加者と研修運営の関係者。

元の会議メモ（記録した順の走り書き）：
---
- 2026-07-08、架空AI研修運営改善会議。参加：研修責任者、研修運営担当、情報システム担当、情報セキュリティ担当（すべて役割名）。
- 入力禁止情報一覧のレビュー：情報セキュリティ担当、2026-07-10まで。
- 録画をどう扱うかは法務確認が必要。録画の可否、確認する担当、期限は未決。
- 終了時チェックリストへのリンクを学習案内へ追加する。決定。
- 来月にフォローアップ会を行う案が出た。実施するかどうかも日程も未決。
- 学習案内の改訂：研修運営担当、2026-07-12まで。
- 次回の初心者研修は、教材の完全な架空データだけを使う。決定。
- 次回会議日は未決。時刻と会場も決まっていない。
- 業務用アカウントのログインテスト：情報システム担当、2026-07-11まで。
- 会議終了時チェックリストを共有フォルダーへ置く。決定。
---

制約：
- 元の会議メモにない決定、担当、期限、日時、参加者を補わない。
- 決定事項、タスク、未決事項を混同しない。
- 担当または期限が書かれていない項目は、推測せず「未決」とする。
- 法的な結論を作らず、「法務確認が必要」という状態を保つ。
- 実在する人物、企業、URLを追加しない。

出力形式：
1. 最初に「Word貼り付け用議事録」と書く。
2. 会議名、開催日、参加者の役割、決定事項、未決事項の順で整理する。
3. 次に「Excel貼り付け用タスク一覧」と書く。
4. タスク一覧は「タスク」「担当」「期限」の3列とし、列の間をタブで区切る。Markdownの表にはしない。
5. タスク一覧には、担当と期限が両方決まっている3件だけを含める。

以上を守って作成してください。
```

> 元の会議メモも上のコードブロックに含まれています。元メモだけを別に送ったり、実際の会社・会議・担当者の情報へ置き換えたりしません。

### 操作2：貼り付けて送る

1. AIの空の入力欄を一度クリックします。
2. `Ctrl+V`を押します。
3. 入力欄の先頭が`あなたは`、末尾が`以上を守って作成してください。`であることを確認します。
4. 実在情報を追加していないことを確認します。
5. 送信ボタンを一度だけクリックします。
6. 回答が最後まで表示されるのを待ちます。同じ指示を繰り返し送りません。[利用上限の表示](../TROUBLESHOOTING.md#無料枠利用回数の上限に達した)や、[成果物を含まない確認質問](../TROUBLESHOOTING.md#aiが確認質問だけを返すまたは前置きを付ける)が返った場合は、続けて送信せず該当する手順を確認します。

### 期待される画面

表現や説明の付け方はAIごとに異なります。通常は、次の二つが回答に含まれます。

1. `Word貼り付け用議事録`：会議情報、決定事項、未決事項
2. `Excel貼り付け用タスク一覧`：見出し1行とタスク3行

短い「承知しました」などの前置きがあっても、二つの見出しと成果物がそろっていれば、同じ指示を送り直さず初回草案として次へ進みます。元の指示では最初の見出しを指定しているため、前置きは出力形式の差です。最終成果物へはコピーしません。プログラムによる処理や厳密な受入テストでは形式不一致になり得ますが、このクイックスタートでは人が必要部分を照合します。

確認質問だけが返り、二つの成果物がない場合は、実在情報や新しい事実を答えに追加しません。[確認質問・前置きへの対応](../TROUBLESHOOTING.md#aiが確認質問だけを返すまたは前置きを付ける)にある定型文を一度だけ送り、それでも出力されない場合は、同ページの再開手順に従います。安全、権限、規約、アカウントに関する警告が表示された場合は、警告を押し切らず操作を停止します。

この時点の出力は草案です。自然な文章に見えても、まだWordやExcelへ貼り付けません。

## 4. 元メモとAI出力を照合する

照合に使う正式な元資料は、[初回演習用の架空会議メモ](../sample-data/beginner_meeting_notes.md)です。AI出力ではなく、必ず元資料を正とします。

### 4.1 会議情報と分類を確認する

AI出力を見ながら、次の表を1行ずつ確認し、`一致`、`不足`、`作り足し`のいずれかを判断します。照合記録も学習成果物として残したい場合だけ、[初回演習ワークシート](../workbooks/beginner_minutes_worksheet.md)を使います。この時点では同ワークシートの「5. 修正と1点改善」へ問題の要約と元メモの根拠だけを書き、修正・再照合後に「1〜4」へ人が確認した最終内容を書きます。通常のWord・Excel経路とMarkdown経路では、初回草案や照合表を保存するための別ファイルは作りません。

| 確認項目 | 元資料の正しい状態 | 結果 |
|---|---|---|
| 会議名 | 架空AI研修運営改善会議 |  |
| 開催日 | 2026-07-08 |  |
| 参加者 | 氏名ではなく4種類の役割だけ。実際の人数は不明 |  |
| 決定事項 | 明記された3件だけ |  |
| 未決事項 | 録画、フォローアップ会、次回会議日の3件 |  |
| 録画の扱い | 法務確認が必要。録画可否、確認担当、期限は未決 |  |
| フォローアップ会 | 実施可否と日程が未決 |  |
| 次回会議 | 日付、時刻、会場が未決 |  |

### 4.2 タスク一覧を確認する

| タスク | 正しい担当 | 正しい期限 | 人の照合結果 |
|---|---|---|---|
| 学習案内の改訂 | 研修運営担当 | 2026-07-12 |  |
| 業務用アカウントのログインテスト | 情報システム担当 | 2026-07-11 |  |
| 入力禁止情報一覧のレビュー | 情報セキュリティ担当 | 2026-07-10 |  |

さらに、次の点を確認します。

- [ ] タスクは3件だけである
- [ ] タスク一覧は見出しと3件があり、各行にタスク・担当・期限の3項目がある（実際に列へ分かれるかはExcel貼り付け後に確認する）
- [ ] AIが担当者名を作っていない
- [ ] 未決事項へ担当や期限を付けていない
- [ ] フォローアップ会を決定事項へ変えていない
- [ ] 次回会議の日付、時刻、会場を作っていない

一つでも一致しなければ、次の手順で修正します。すべて一致していても、[6. プロンプトを一つ改善する](#6-プロンプトを一つ改善する)は実施します。

## 5. 誤りや不足がある場合は同じチャットで修正する

### 誤りがない場合

この節ではAIへ何も送らず、[6. プロンプトを一つ改善する](#6-プロンプトを一つ改善する)へ進みます。

### 誤りがある場合

1. 新しいチャットを開かず、先ほどの回答の下にある入力欄をクリックします。
2. 次の文の`{見つけた問題}`を、照合で見つけた内容へ置き換えます。
3. 全文を送信します。
4. 修正版を受け取ったら、[4. 元メモとAI出力を照合する](#4-元メモとai出力を照合する)をもう一度行います。

```text
元の会議メモとの照合で、次の問題が見つかりました。
- {見つけた問題}

元の会議メモにない決定、担当、期限は追加せず、その問題だけを修正してください。
議事録とタスク一覧を修正後の全文で再出力してください。
```

置き換え例：

```text
- 録画確認の担当は未決なのに、研修運営担当と書かれている
```

AIが直したと述べても、必ず元資料と再照合します。同じ誤りが残る場合は、指示を具体化して一度だけ再生成し、それでも直らなければ最終成果物を人が修正します。AIへ修正を指示して再生成する工程は省略しません。組織利用では必要に応じて正式窓口へ確認します。

## 6. プロンプトを一つ改善する

実務では、内容を正しくするだけでなく、使う人が扱いやすい順序へ整えます。今回は**タスクを期限の早い順にする**という一つの改善だけを追加します。

1. 修正に使ったものと同じチャットの入力欄をクリックします。
2. 次のコードブロックをコピーして送信します。

```text
内容、担当、期限は変えず、Excel貼り付け用タスク一覧だけを期限の早い順に並べ替えてください。
Word貼り付け用議事録も含め、最終版の全文を再出力してください。
元の会議メモにない情報は追加しないでください。
```

3. タスクが次の順になったことを確認します。
   1. 入力禁止情報一覧のレビュー：2026-07-10
   2. 業務用アカウントのログインテスト：2026-07-11
   3. 学習案内の改訂：2026-07-12
4. 並べ替え以外の内容が変わっていないか、照合表でもう一度確認します。

これが「プロンプトの改善」です。AIへ「もっとよくして」と頼むのではなく、何をどう変えるかを具体的に伝えます。

## 7. Wordで完成議事録を作る

利用できるWordのデスクトップ版またはWeb版を使います。組織利用では指定された環境だけを使い、個人登録や無断インストールをしません。個人学習でWordがなければMarkdown経路へ進みます。

1. デスクトップ版を指定された場合は、Windowsの「スタート」をクリックし、`Word`を検索して「Microsoft Word」をクリックします。
2. Web版では、個人学習は確認済みの公式サイト、組織利用は指定ポータルを開き、使用可能なアカウントで「Word」→「新しい空白の文書」の順に進みます。
3. どちらの場合も「白紙の文書」または「新しい空白の文書」を開きます。
4. AIの最終回答へ戻ります。
5. `Word貼り付け用議事録`という見出しから、未決事項の最後までを選択します。`Excel貼り付け用タスク一覧`は選択しません。
6. `Ctrl+C`を押します。
7. Wordの白紙部分をクリックし、`Ctrl+V`を押します。
8. 会議名、開催日、参加者の役割、決定事項、未決事項があることを確認します。
9. 日付、決定、未決事項が元資料と一致することをもう一度確認します。
10. Word上で、読みやすさのための改行や見出しだけを整えます。事実、担当、期限は書き足しません。
11. デスクトップ版では「ファイル」→「名前を付けて保存」、Web版では確認済みの保存またはダウンロード操作を選びます。
12. 個人学習ではローカル学習用フォルダー、組織利用では指定保存先を選び、`完成議事録.docx`として保存します。

保存後、Wordのタイトルバーなどに`完成議事録.docx`と表示されることを確認します。メール送信、共有リンク作成、クラウド公開は行いません。

## 8. Excelでタスク一覧を作る

組織から指定されたExcelのデスクトップ版またはWeb版を使います。自分で新しく個人登録したり、Excelを無断でインストールしたりしません。

1. デスクトップ版を指定された場合は、Windowsの「スタート」をクリックし、`Excel`を検索して「Microsoft Excel」をクリックします。
2. Web版では、個人学習は確認済みの公式サイト、組織利用は指定ポータルを開き、使用可能なアカウントで「Excel」→「新しい空白のブック」の順に進みます。
3. どちらの場合も「空白のブック」または「新しい空白のブック」を開きます。
4. AIの最終回答へ戻ります。
5. `タスク`で始まる見出し行から、3件目のタスク行までを選択します。`Excel貼り付け用タスク一覧`という説明見出しは含めません。
6. `Ctrl+C`を押します。コードブロックで表示された場合は、コードブロック内の4行だけをコピーします。
7. Excelのセル`A1`を一度クリックします。
8. `Ctrl+V`を押します。
9. A列からC列に、`タスク`、`担当`、`期限`が分かれていることを確認します。
10. 2行目から4行目までに、期限の早い順で3件のタスクがあることを確認します。

### デスクトップ版ですべてA列へ入った場合

1. データが入ったA列のセルを選択します。
2. Excel上部の「データ」をクリックします。
3. 「区切り位置」をクリックします。
4. 「コンマやタブなどの区切り文字によってフィールドごとに区切られたデータ」を選び、「次へ」をクリックします。
5. 区切り文字の「タブ」だけにチェックを入れます。
6. プレビューが3列になったことを確認し、「完了」をクリックします。

### Web版ですべてA列へ入った場合

1. `Ctrl+Z`で貼り付けを取り消します。
2. 自分の判断で機能追加、別サービスへのアップロード、個人版への切り替えをしません。
3. 同じ貼り付けを繰り返さず、[トラブル対応](../TROUBLESHOOTING.md#tsvを貼り付けてもexcelで1列になる)を確認します。
4. 確認済みの読み込み方法、空のExcel様式、または[Officeを利用できない場合](#9-officeを利用できない場合)の方法へ切り替えます。

Web版では、デスクトップ版と同じ「区切り位置」の操作を前提にしません。個人学習では公式情報、組織利用では正式な利用案内で事前に確認した方法だけを使います。

### 見やすくして保存する

1. A列からC列の見出しを確認します。
2. 列見出し`A`と`B`の境界、`B`と`C`の境界をダブルクリックし、文字が見える幅へ調整します。
3. 内容、担当、期限を元資料と再照合します。
4. デスクトップ版では「ファイル」→「名前を付けて保存」、Web版では確認済みの保存またはダウンロード操作を選びます。
5. 個人学習ではローカル学習用フォルダー、組織利用では指定保存先を選び、`タスク一覧.xlsx`として保存します。

数式、マクロ、自動送信、外部データ接続は使用しません。

## 9. Officeを利用できない場合

WordまたはExcelのどちらか一方でも利用できない場合は、成果物が分散して迷わないよう、この節で議事録とタスク一覧の両方をMarkdownまたは紙へまとめます。これは成果物を記録する形式の変更であり、手順3〜6のAIの実操作は必須です。

### Markdownで保存できる場合

1. OS標準または本人・組織が利用を認めたテキストエディターを開きます。
2. AIの最終回答から、議事録とタスク一覧の両方を貼り付けます。
3. タスク一覧が読みにくい場合は、次の見出しを使って3項目ずつ箇条書きにします。
   - タスク
   - 担当
   - 期限
4. 元資料と最終照合します。
5. 指定保存先へ`AI研修運営改善会議_成果物.md`として保存します。

### 紙へ記録する場合

1. [初回演習ワークシート](../workbooks/beginner_minutes_worksheet.md)をローカルへコピーするか印刷します。
2. 議事録欄へ、会議名、開催日、参加者の役割、決定事項、未決事項を書きます。
3. タスク欄へ、期限の早い順でタスク、担当、期限を書きます。
4. 元資料と照合してチェックを付けます。
5. 完成した用紙は、個人学習では安全な場所へ保管し、組織利用では指定手順に従います。個人クラウドやSNSへ撮影・投稿しません。

## 10. AIを使えない場合

AIが未承認、ログインできない、通信障害がある、または利用上限により回答を生成できない場合は、入力を止めて次の準備を行います。この状態では本演習を完了できません。

1. 個人学習では、利用上限の場合は公式表示に従って時間を置くか、本人が規約、料金、データ設定を確認できる別の対話AIを検討します。
2. 組織利用では、私物アカウントを作らず正式窓口へ承認または復旧を依頼します。
3. 承認済み対話AIへ接続できたら、[共通準備の接続確認](common_preparation.md#7-接続確認)を行います。
4. 接続確認に成功してから、[2. 対話AIを開く](#2-対話aiを開く)へ戻ります。

[初回演習用の保存済み問題例](../sample-outputs/beginner_minutes_saved_output.md)は、AIの誤りを探す追加練習や障害の切り分けにだけ使用できます。保存済み出力の修正だけでは、AIへの指示と改善を実操作していないため、本演習の代替や完了条件にはなりません。
