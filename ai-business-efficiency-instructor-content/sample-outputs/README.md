# 保存済み代替出力

このフォルダーには、アカウント、通信、管理設定などの理由でAIツールを利用できない場合に使う固定教材があります。AIを利用できる場合も、自力課題を終えた後の比較材料として使えます。

## 重要な注意

- 実際の製品が生成した最新出力や、現在の画面を再現する資料ではありません。
- すべて完全な架空データから作った教育用の例です。
- 良い例だけでなく、誤り・根拠不足・停止すべき例も含みます。
- 正解として写すのではなく、元資料との照合、問題発見、修正、停止を練習します。
- 製品の機能・画面・契約条件は、利用前に各社の最新公式情報で確認します。

## 利用手順

1. 対応する演習本文から、開くタイミングと対象ファイルを確認します。
2. 手順付き例または自力課題を先に行います。AIなし経路では、演習が指定した段階で保存済み出力を開きます。
3. 対応する`sample-data/`の元資料を確認します。
4. 保存済み出力を、AIが生成した草案だったものとして読みます。
5. 元資料にない決定、担当、期限、根拠がないか照合します。
6. 問題を修正し、自分で確認した最終成果物だけを安全な場所へ保存します。
7. 保存済み出力そのものを、完成品として外部送信・公開しません。
