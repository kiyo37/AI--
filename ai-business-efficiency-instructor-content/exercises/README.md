# 実務ハンズオン演習ガイド

このページは、一人で実務に近い演習を進めるための入口です。すべての演習で、**架空データを使う→AIの草案を元資料と照合する→誤りを1点以上直す→利用範囲と停止条件を決める**ところまで行います。ペア確認は任意であり、一人でも完了できます。

## 最初に確認すること

- 個人学習では、利用するAIの公式URL、規約、プライバシー設定、料金を本人が確認します。
- 組織で学ぶ場合は、組織が承認したAI、業務用アカウント、保存先、相談先を優先します。
- すべての演習で、本人または組織が利用を認めた対話AIの実操作が必要です。特定製品を使えない場合は、別の承認済み対話AIを使います。
- 承認済み対話AIを利用できない、ログインできない、または通信障害が続く場合は、[共通準備](../setup/common_preparation.md)へ戻って環境を整えます。AIを操作できるまで演習を停止し、完了扱いにしません。
- `sample-outputs/`の保存済み問題出力は、自分でAIを実行した後の誤り発見・比較、または実行後に障害が起きた場合の補助教材です。AI実操作の代わりにはなりません。
- 入力には`sample-data/`の完全な架空データだけを使い、実在の業務情報、個人情報、認証情報へ置き換えません。
- AI出力は元資料や規程と自分で照合し、外部送信、公開、支払、本番システムへの書込みを行いません。
- 製品の画面や機能は変わるため、操作前に最新の公式情報を確認します。

最初に[学習スタートガイド](../START_HERE.md)を読み、[クイックスタート](../setup/participant_quickstart.md)の導入演習を終えてください。

## おすすめの順序

| 順番 | 演習 | 作るもの | 主に練習すること |
|---:|---|---|---|
| 1 | [メール・議事録・報告書](email_minutes_report_exercises.md) | 返信文、議事録、報告書、要約 | 指示、元資料照合、用途別の書き分け |
| 2 | [Zoom・Teams共通のテレビ会議議事録](video_meeting_minutes_exercises.md) | 検証済み議事録、根拠位置付きタスク一覧 | 文字起こしの誤りを人が見つける |
| 3 | [問い合わせ明細からExcel月次報告](inquiry_excel_monthly_report_exercises.md) | 分類済み明細、集計表、月次報告 | AI候補と確定値を分け、全件・合計・数式を照合する |
| 4 | [引継ぎメモから業務マニュアル](business_manual_creation_exercises.md) | テスト済み手順書、例外処理、改訂履歴 | 不足を質問し、4つの架空ケースで手順を試す |
| 5 | [プロンプト受入テスト](prompt_acceptance_testing_exercises.md) | v1・v2、テスト記録、利用範囲、停止条件 | 同じケースで改善前後と副作用を確認する |
| 6 | [業務プロセスマッピング](business_process_mapping_exercises.md) | Before／After、役割分担 | AI・人・通常の自動化を切り分ける |
| 7 | [AI利用リスク判断](risk_judgment_exercises.md) | 入力可否、停止、相談の判断記録 | 情報・正確性・権利・高影響判断を見分ける |
| 8 | [業務ヒアリングからAI活用試行提案](business_interview_improvement_proposal_exercises.md) | Before、試行案、1ページ提案 | 事実・仮定・未確認を分け、業務から改善を設計する |

一つだけ選ぶこともできます。ただし、各演習の前提章、安全条件、人による元資料照合は省略しません。

## 全演習に共通する進め方

| 段階 | 行うこと |
|---:|---|
| 1. 目的 | 完成させる業務成果物と、AIを使う理由を確認する |
| 2. 準備 | 個人学習／組織利用の経路から一つ選び、承認済み対話AIと収録ファイルを開く |
| 3. 手順付き例 | 最初の一部だけ、解説を読みながら処理する |
| 4. 自力課題 | 残りを先に自分で作業し、自己点検資料をまだ見ない |
| 5. 元資料照合 | AI出力を正解扱いせず、一次資料、規程、CSV、確認カードへ戻る |
| 6. 段階ヒント | 詰まった箇所だけヒント1から順に開く |
| 7. 自己点検 | `self-check/exercises/`の対応ガイドと比較し、根拠を確認する |
| 8. 1点修正 | 誤りまたは改善点を最低1点直し、修正理由を残す |
| 9. 完了・次へ | 完了条件と安全な終了を確認し、次の演習へ進む |

自己点検ガイドは唯一の正解ではありません。先に成果物を作ってから開き、文章の一致ではなく、事実、根拠、例外、停止条件、人間確認がそろっているかを見ます。

## 成果物を実務へつなぐとき

演習成果物は架空ケースの練習結果であり、実務利用の承認ではありません。[実務転用シート](../workbooks/work_transfer_sheet.md)には実データを書かず、業務の種類、想定する情報区分、確認者、停止条件、相談先だけを記入します。実データによる試行は、所属組織の正式な承認と安全な環境がそろった後に別途行います。

## 自己点検ガイド

演習を終えた後は[演習別自己点検ガイド一覧](../self-check/README.md#演習別の自己点検)から対応するファイルを開きます。
