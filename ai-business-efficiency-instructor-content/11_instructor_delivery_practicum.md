# 11 AI業務効率化講師の登壇・改善実践

> 用語に迷ったときは、[用語集](glossary.md)も参照してください。

## 1. この章の目的

設計した教材を、安全かつ分かりやすく届ける登壇力を身につけます。説明、問いかけ、演習進行、質疑、反対意見、デモ失敗、進行管理を模擬講義で練習し、観察した事実から改善します。

本章で使う**観察記録**は、点数や合否を付ける表ではありません。講師と受講者に起きた事実、よかった工夫、迷いが生じた場面、次に変える行動を書き残すものです。話し方の好みではなく、受講者の理解、安全な進行、質疑対応など、実際に見聞きできた行動を記録します。

## 2. 学習ゴール

- 専門用語を「一言説明・例・注意点」で説明できる
- 受講者の発言を引き出し、誤解を安全に修正できる
- 答えられない質問を推測せず、確認先と回答期限を示せる
- デモや通信が失敗しても、紙上演習へ切り替えられる
- 目的に合わせた任意の長さのミニ講義を行い、非採点の観察記録で改善できる
- ChatGPTを受講者役として使う場合も、最終的な観察と改善判断は人が行える

## 3. 本編解説

### 3.1 講師に必要な5つの実践能力

| 能力 | 観察できる行動 | よくある失敗 |
|---|---|---|
| 説明 | 定義、業務例、限界を短く話す | 用語を別の用語で説明する |
| 進行 | 目的、区切り、手順、提出物を明示する | 説明が長く演習を圧迫する |
| 問いかけ | 判断理由と根拠を受講者から引き出す | 正解をすぐ講師が言う |
| 安全管理 | 入力前確認、停止、相談を実演する | デモの便利さを優先する |
| 改善 | 観察記録から次回の行動を一つ変える | 満足度だけで成功とする |

### 3.2 初心者へ説明する5段階

1. **結論**：「生成AIは下書きの補助で、最終判断者ではありません」。
2. **一言定義**：専門用語を一文の平易な言葉で説明する。
3. **身近な例**：メール、会議、報告など受講者の業務へつなぐ。
4. **非例・限界**：非例とは、その用語に当てはまらない例や不適切な使い方の例です。「医療判断を任せる」のような非例を示します。
5. **確認質問**：「この例で人が確認するのは何ですか」と問い返す。

スライドを読み上げるのではなく、受講者が自分で判断を言葉にする時間を作ります。

### 3.3 ファシリテーションの基本

**ファシリテーション**は、参加者の発言や作業を促し、学習目標へ沿って場を進めることです。

| 場面 | 講師の問いかけ例 |
|---|---|
| 業務分解 | 「開始と完了は何ですか」「誰が承認しますか」 |
| リスク判断 | 「何が起きたら困りますか」「誤りをどう見つけますか」 |
| プロンプト改善 | 「どの要件が不足していますか」「完成条件は何ですか」 |
| 事実確認 | 「その主張を支える原文はどこですか」 |
| 振り返り | 「AIへ任せなかった部分と、その理由は何ですか」 |

沈黙があってもすぐ答えを言わず、個人思考→ペア相談→全体共有の順にすると参加しやすくなります。

### 3.4 反対意見・不安への対応

| 発言例 | 避ける応答 | 推奨する応答 |
|---|---|---|
| 「AIは危険だから全部禁止すべき」 | 危険ではないと否定 | 懸念を具体化し、禁止・条件付き・許可へ分ける |
| 「AIなら必ず時短できる」 | 成功例だけを示す | 確認時間を含むBefore / Afterで検証する |
| 「自分の仕事がなくなる」 | 大丈夫と断定 | 変わる作業、残る判断、必要な学習を業務単位で整理する |
| 「別のAIでは違う回答だった」 | 正解の製品を決める | 元資料と確認基準で比較する |
| 「会社のルールが分からない」 | 一般論で許可する | 入力を止め、正式な相談先を確認する |

講師は不安を値踏み・否定せず、「何が不明か」「誰が決めるか」「次に何を確認するか」へ変換します。

### 3.5 質疑応答の境界

質問へ即答することより、誤答しないことを優先します。

```text
現時点では断定できません。
確認が必要なのは、{法令・契約・製品仕様・社内規程・個別事情}です。
{公式情報／担当部門／専門家}へ確認し、{期限・方法}で回答します。
それまでは{入力・公開・実行}を止めてください。
```

| 質問 | 講師が答えられる範囲 | 引き継ぐ先 |
|---|---|---|
| 製品の操作 | 確認済み環境の一般手順 | 管理者・公式サポート |
| 自社の入力可否 | 判断枠組みと確認事項 | セキュリティ・個人情報担当 |
| 著作権・契約の個別判断 | 一般的論点 | 法務・知財・専門家 |
| 医療・金融・法律の助言 | AIを最終判断にしない原則 | 有資格の専門家 |
| 事故・誤入力 | 停止・記録・報告 | 社内の事故対応窓口 |

未回答は、質問、質問者、確認先、担当、回答期限、回答内容を一覧で管理します。

### 3.6 安全なライブデモ

| デモ前 | デモ中 | デモ後 |
|---|---|---|
| 架空データ、通知非表示、履歴・タブ確認 | 入力内容を読み上げ、送信前に一度止まる | 出力の誤りと確認箇所を示す |
| 承認済みアカウント・機能を確認 | 外部送信・実システム実行をしない | 会話・ファイルの保存条件を確認 |
| 成功例、失敗例、画像、紙上代替を準備 | 予想外の出力を正解扱いしない | デモ結果を教材の固定仕様にしない |

通信・アカウント障害時は、事前に決めた切替条件に達したら復旧操作を打ち切り、保存済みの出力例または紙上演習へ切り替えます。切替条件は「再ログインを試しても利用できない」「受講者が演習を開始できない」など、観察できる状態で決めます。

### 3.7 任意の長さに対応する進行管理

先に講義時間を固定するのではなく、学習目標に必要な活動を並べ、依頼者と相談して範囲を調整します。短くする場合は目標を絞り、演習や人間レビューを削って説明だけにしません。

| 進行の区切り | 内容 | 講師の行動 | 次へ進む目安 |
|---|---|---|---|
| 導入 | 目的・安全ルール | 終了時の行動と扱わない範囲を示す | 受講者が演習条件を言い直せる |
| 短い説明 | 一言定義、例、限界 | 専門用語を平易な表現へ言い換える | 身近な業務例と結び付く |
| 例の観察 | デモまたは出力比較 | 見るポイントを先に示す | 受講者が問題箇所を指摘できる |
| 受講者演習 | 個人・ペア・紙上のいずれか | 進捗を確認し、答えを言いすぎない | 提出物と判断理由がそろう |
| 対話 | 共有、誤解修正、質疑 | 根拠を尋ね、不明事項を記録する | 次の確認先が明確になる |
| 障害対応 | 通信・出力・質問の想定外へ対応 | 停止、代替、引継ぎを実演する | 安全に学習を継続できる |
| 振り返り | 行動、停止条件、相談先 | 次に変える行動を言語化する | 観察記録へ改善点が残る |

### 3.8 アクセシブルな進行

**アクセシビリティ**は、障害、年齢、利用端末などにかかわらず参加・理解しやすくする配慮です。

- 色だけで正誤を区別せず、文字・記号も使う
- 小さな文字や横に長すぎる表を避け、配布版を用意する
- 動画に字幕、画像に代替説明、口頭指示に書面を用意する
- キーボード操作や紙上参加など代替手段を用意する
- 読み書き・発言速度だけで理解度を判断しない
- 休憩、ペア選択、匿名質問など参加方法を複数にする

必要な配慮は本人・研修担当者へ事前確認し、個人の事情を全体へ無断共有しません。

### 3.9 模擬講義の非採点観察記録

**責任分界**とは、AI、利用者、承認者、管理者などが、それぞれどこまで確認・判断・対応するかを区切ることです。

| 観察項目 | 完成条件 | 観察した事実 | 改善ポイント |
|---|---|---|---|
| 目標 | 受講者が行う行動、演習、振り返りがつながっている | 何を見聞きしたかを書く | 次回に変える具体的な行動を書く |
| 説明 | 用語を一言の意味、例、非例・限界で説明している | 同左 | 同左 |
| 問いかけ | 受講者の判断理由と根拠を引き出している | 同左 | 同左 |
| 安全 | 入力前確認、停止、相談、代替を実演している | 同左 | 同左 |
| 演習 | 操作だけでなく、検証・修正・人間判断を含む | 同左 | 同左 |
| 質疑 | 不明時に推測せず、確認先・暫定対応・記録方法を示す | 同左 | 同左 |
| 進行 | 受講者の反応に応じて範囲を調整し、演習と振り返りを守る | 同左 | 同左 |
| 配慮 | 資料、発言、操作に複数の参加方法がある | 同左 | 同左 |

観察者は「分かりやすかった」のような感想だけで終えず、「講師がベクトル検索を『意味の近い資料を探す方法』と言い換え、受講者が自分の例を説明できた」のように事実を書きます。安全上の問題が見つかった場合は合否を付けず、公開・入力・実行を止め、修正後に再度観察します。

## 4. 実務での使いどころ

- 初登壇前の社内模擬講義
- 顧客向けデモの安全確認
- 講師同士の相互観察と標準化
- 研修事故・アンケート・未回答質問を使った改善会議

## 5. 講師メモ

- 流暢さより、説明の正確さ、受講者の判断、安全な停止を観察します。
- 模擬講義の録画は、参加者の同意、保存期間、閲覧範囲を決めます。
- 反対意見を「抵抗」と片付けず、未解決の業務・安全要件として扱います。
- 受講者の質問に個人情報・機密が含まれそうなら、発言を止めて**架空化**（実在する氏名、組織、数値などを、一から作った架空情報へ置き換えること）します。単に氏名を伏せるだけで安全と判断しません。
- 講師自身のAI出力も根拠確認し、訂正が必要な場合は記録して周知します。

## 6. 演習

### 演習：任意の長さのミニ講義と障害対応

`01〜10`から一つのテーマを選び、学習目標に必要な長さでミニ講義を行います。ChatGPTを受講者役として使えますが、講師としての最終的な観察と改善判断はAIではなく人間の観察者が行います。

#### 1. 利用環境の準備確認

| 状況 | 進め方 |
|---|---|
| 個人学習 | 本人が管理するChatGPTアカウントと完全な架空データを使う。履歴・共有設定を確認する |
| 企業研修 | 組織が承認・発行したアカウントだけを使う。講師判断で個人登録させない |
| ChatGPTだけ利用可能 | ChatGPTを受講者役にし、人間が観察記録を付ける |
| 未承認・利用不可 | ペアまたは講師自身が受講者役を担当し、配布した想定質問カードを使う |

[対話AIのアカウント準備](setup/chat_ai_account_setup.md)を先に確認します。実在受講者の個人情報、顧客名、社内機密はプロンプトへ入力しません。

#### 2. ガイド付き練習

ChatGPTを利用できる場合は、次のプロンプトで受講者役を依頼します。

```text
あなたは生成AIを初めて学ぶ架空の受講者です。
私の説明に対し、一度に一つだけ質問してください。
難しい専門用語、業務での使い方、安全上の不安について、
初心者が実際に迷いそうな質問をしてください。
私の説明に根拠がない場合は「何を確認すればよいですか」と尋ねてください。
個人情報・機密情報を作らず、回答の正誤を最終判定しないでください。
```

講師は「一言の意味→例→限界→確認質問」の順で回答します。ChatGPTの質問や感想も誤る可能性があるため、正解や採否の判定には使いません。

#### 3. 実務演習

1. 行動目標、扱わない範囲、完成条件を決めます。
2. 完全な架空データを使う演習と、人間レビューを組み込みます。
3. 観察者は途中で「通信障害」「AIが入力外の事実を生成」「法的な個別質問」などのカードを提示します。
4. 講師は安全に停止し、保存済み出力・紙上演習へ切り替えるか、専門家へ引き継ぎます。
5. 人間の受講者がいる場合は理解・不安・参加しやすさを尋ねます。AIの受講者役は補助として使います。

#### 4. 人間レビュー

[模擬登壇観察シート](templates/instructor_observation_sheet.md)を使い、点数を付けずに次を記録します。

- 受講者が言い直せた内容、迷った内容
- 講師が根拠・限界・相談先を示した場面
- 入力や実行を止めるべき場面で実際に止めたか
- 演習と人間レビューを守りながら進行を調整したか
- 資料、発言、操作に代替手段があったか

ChatGPTが出した講評は参考意見にとどめ、観察した事実と異なる場合は採用しません。

#### 5. 振り返り

- 受講者役から出た質問のうち、説明を追加すべきものは何か。
- 答えられなかった質問を、誰がどの公式情報・社内窓口・専門家へ確認するか。
- 障害時の切替条件は明確で、受講者へ説明できたか。
- 次回に変える講師行動を一つ決め、改訂した台本へ反映する。

**役割**：講師、受講者、観察者。少人数では受講者役をChatGPTまたは質問カードで補いますが、人間の観察者は省きません。

**提出物**：任意長のミニ講義案、スライドまたは配布資料、演習、未回答質問票、非採点の観察記録、改善記録。

## 7. 実務チェックリストと振り返り

この節は採点しません。登壇前後に、自分が安全な行動を実演できるか確認します。

- [ ] 専門用語を一言の意味、業務例、限界の順で説明できる
- [ ] 受講者へ判断理由と根拠を尋ねられる
- [ ] 法律・著作権・個人情報・医療・金融などの個別判断を断定せず、専門家へつなげられる
- [ ] 不明な製品仕様は最新の公式情報を確認すると案内できる
- [ ] デモ障害時に、事前に決めた条件で保存済み出力または紙上演習へ切り替えられる
- [ ] ChatGPTの受講者役を補助にとどめ、人間が観察・改善判断できる
- [ ] 点数ではなく、観察した事実と次に変える行動を記録できる
- [ ] 個人・企業・未承認の利用環境に応じて演習を切り替えられる

**振り返り**：講師の説明後、受講者がどの行動を自分で実演できましたか。観察できた事実を書き、次回に変える行動を一つ決めてください。答えられなかった質問は、確認先と暫定対応を未回答質問票へ残してください。

## 8. まとめ

講師の価値は、知識量だけでなく、受講者が安全に判断できる場を作ることにあります。短く説明し、根拠を問い、誤答を修正し、不明時は確認先へつなぎます。デモ失敗や反対意見も事前に練習し、模擬講義の観察記録から改善を続けます。
