# 06 ハルシネーションとファクトチェック 講師用成果物例

- 対応演習：ChatGPTの誤答候補をPerplexityと公式原文で検証する
- 公式情報の確認日：2026-08-02

## 1. 利用上の注意

- ChatGPTは未検証文を主張へ分解する補助、Perplexityは出典候補を探す補助として使います。どちらも事実の最終確定者ではありません。
- Perplexityの回答文や検索結果の抜粋だけで判定せず、引用先の公式ページを人間が開き、該当箇所を読みます。
- 製品仕様と公式ページは更新されます。本書にあるブラウザ情報を暗記せず、実施日に最新の公式原文を再確認します。
- 企業研修では個人アカウントの登録を求めません。未承認、登録不可、通信障害の場合は、URL・確認日・該当見出し付きの公式ページ印刷物を使います。
- 法律、医療、金融、個人の権利義務等の個別判断を本演習で確定しません。最新の一次情報を確認し、担当部署または有資格の専門家へ引き継ぎます。
- AI出力は人間が確認してから業務利用します。

## 3. ガイド付き練習：模範成果物

### 3.1 検証対象

```text
PerplexityのWebアプリはChrome 120以降とSafari 15以降だけに対応しています。
FirefoxとMicrosoft Edgeは非対応です。情報は2026年に更新されています。
```

これは教材作成時点の公式情報と意図的に食い違わせた誤答候補です。

### 3.2 ChatGPTによる主張分解の例

ChatGPTには事実確認をさせず、検証単位を作らせます。

| ID | 検証する主張 | 確認対象 | 望ましい一次情報 |
|---|---|---|---|
| C-01 | 対応ブラウザはChromeとSafariだけである | 対応ブラウザ一覧 | Perplexity公式ヘルプ |
| C-02 | Chromeは120以降に対応する | Chromeの最低バージョン | Perplexity公式ヘルプ |
| C-03 | Safariは15以降に対応する | Safariの最低バージョン | Perplexity公式ヘルプ |
| C-04 | Firefoxは非対応である | Firefoxの掲載有無と条件 | Perplexity公式ヘルプ |
| C-05 | Microsoft Edgeは非対応である | Edgeの掲載有無と条件 | Perplexity公式ヘルプ |
| C-06 | 根拠ページは2026年に更新された | ページの最終更新日 | 同じ公式ページの更新表示 |

望ましいChatGPT出力は、正しさを断定せず、数値、限定語、対応可否、日付を別々にしたものです。

### 3.3 Perplexityによる出典候補探索の例

検索文例：

```text
Perplexity Webアプリの対応ブラウザを、Perplexity公式ヘルプだけから探してください。
公式ページ名、URL、更新日を示し、確認できない情報は推測しないでください。
```

出典候補として[Perplexityウェブアプリ対応ブラウザ](https://www.perplexity.ai/help-center/ja/articles/11502647-perplexity%E3%82%A6%E3%82%A7%E3%83%96%E3%82%A2%E3%83%97%E3%83%AA%E5%AF%BE%E5%BF%9C%E3%83%96%E3%83%A9%E3%82%A6%E3%82%B6)が示されたら、検索画面の要約で止めず、リンクを開きます。

### 3.4 公式原文との照合例

下表は2026-08-02に公式ページを人が確認した記録例です。後日の演習では再確認して更新します。

| ID | 判定例 | 公式原文から確認した要旨 | ページ更新日 | 確認日 | 条件・注意 |
|---|---|---|---|---|---|
| C-01 | 誤り | ChromeとSafari以外も掲載されている | 2026-07-03 | 2026-08-02 | 一覧は包括的ではないという注意がある |
| C-02 | 誤り | Chromeは122以降と案内されている | 2026-07-03 | 2026-08-02 | 後日変わる可能性がある |
| C-03 | 誤り | Safariは16以降と案内されている | 2026-07-03 | 2026-08-02 | OS側の条件も別途確認する |
| C-04 | 誤り | Firefoxは135以降として掲載されている | 2026-07-03 | 2026-08-02 | 最新の公式ページを優先する |
| C-05 | 誤り | Microsoft Edgeは132以降として掲載されている | 2026-07-03 | 2026-08-02 | 組織の許可ブラウザも確認する |
| C-06 | 確認済みだが表現不足 | 公式ページに2026年の更新表示がある | 2026-07-03 | 2026-08-02 | 「2026年」だけでなく具体日を記録する |

公式ページには、このほかPerplexityのComet、Brave、Arcに関する案内もあります。ここでは候補文の主張に必要な範囲を記録し、完全な一覧が必要な場合は原文を参照します。

### 3.5 安全な修正文の例

```text
2026年8月2日にPerplexity公式ヘルプを確認したところ、Webアプリの対応例として
Chrome 122以降、Firefox 135以降、Microsoft Edge 132以降、Safari 16以降が案内されています。
公式ページは一覧が包括的ではないとも説明しています。
製品仕様は変わるため、利用時に公式ページと組織のブラウザ方針を再確認してください。
```

修正文では、確認日、公式発行元、対象、条件、変更可能性を示します。検索結果の文章を長く転載せず、要旨とURLを記録します。

### 作業記録例

| 工程 | 実施内容 | 残した記録 |
|---|---|---|
| 質問を限定 | 対象製品、基準日、用途を明記 | 質問文 |
| ChatGPT | 未検証文を最小の主張へ分解 | 主張IDと確認項目 |
| Perplexity | 公式ドメインの出典候補を探索 | 検索文、候補URL |
| 公式サイト | リンク先の該当箇所を人が確認 | ページ名、日付、見出し、要旨 |
| 判定 | 主張ごとに確認済み・誤り・不明を記録 | 判定理由と不足情報 |
| 修正 | 確認できた内容だけで回答を書き直す | 修正文と確認者 |

公式情報が見つからない場合の模範対応は「まとめ記事で補う」ではなく、「不明と記録し、回答から外すか公式窓口へ確認する」です。

## 5. 人間レビュー：記録例

| レビュー指摘 | 修正例 | 理由 |
|---|---|---|
| Perplexityの要約だけを根拠にした | 公式ページを開き、該当見出しと確認日を追加 | 出典表示もAI処理を含むため |
| URLが公式なので全主張を確認済みにした | 主張ごとに本文との一致を再確認 | URLの実在と主張の該当は別だから |
| 更新日だけを見た | 対象仕様の基準日と適用条件を追加 | ページ更新日と内容の適用時点は別だから |
| 「おそらく」を確認済みにした | 不明へ変更し、確認先を記載 | 推測で空欄を埋めないため |
| 同じ質問をChatGPTへ再入力した | 一次情報と別の人による照合へ変更 | 同じ誤りを繰り返す可能性があるため |

## 6. 振り返り：記入例

- 信じそうになった表現：「だけに対応」「非対応」のような断定と具体的な数字。
- Perplexityだけでは分からなかったこと：検索要約が公式ページの注意書きを省いている可能性。
- 原文を開いて変わった判断：FirefoxとEdgeの扱い、最低バージョン、一覧が包括的ではない点。
- 今後残す情報：質問、基準日、公式URL、ページ更新日、確認日、該当見出し、確認者。

## 7. 観察ポイントと改善例

| 観察ポイント | 望ましい様子 | 改善例 |
|---|---|---|
| 主張分解 | 数値、日付、限定語、条件を別々にする | 一文を丸ごと判定している場合は一事実ずつ分ける |
| ツールの役割 | ChatGPTは分解、Perplexityは探索、人は原文照合 | AIに最終判定させた場合は役割表へ戻る |
| 出典確認 | 公式リンクの該当箇所を読む | 検索抜粋だけなら原文の見出しと要旨を記録する |
| 日付 | 発行・更新日と内容の基準日を区別する | 「最新」とだけ書いた場合は具体日を追加する |
| 不明の扱い | 推測せず不明を残す | 断定へ直した場合は根拠の有無を再確認する |
| 高リスク領域 | 一般論の整理にとどめ専門家へ引き継ぐ | 個別助言を作った場合は利用を止め、担当者へ渡す |

## 8. 別解・ツール利用不可時の紙上例

### 許容できる別解

- ChatGPTを使わず、人が誤答候補を蛍光ペンで主張へ分ける。
- Perplexityを使わず、通常の検索エンジンで公式ドメインを指定して探す。
- 公式原文しかない場合は、検索AIを介さず直接照合する。
- 判定名が異なっても、根拠と不明点が明確ならよい。「部分確認」等を追加してもよい。

### 紙上例

1. 講師が誤答候補、ChatGPTの主張分解例、Perplexityの検索例を配布します。
2. 受講者は主張ごとに切り分け、検証台帳へ貼ります。
3. URL、確認日、該当見出し付きの公式ページ印刷物から根拠へ線を引きます。
4. 「確認済み・誤り・不明」を付け、断定を避けた修正文を紙へ書きます。
5. 別の受講者が原文と台帳を照合します。

紙上でも、AI要約と公式原文を区別し、確認日と不明点を残せれば同じ学習成果になります。

## 9. 講師向け補足

製品のブラウザ仕様を覚えさせる演習ではありません。具体的で自然な誤答を主張へ分け、検索AIの引用先を開き、公式原文で条件を確認する習慣を作ります。実施前に必ず公式ページを再確認し、本書の数値が変わっていれば検証記録を更新してください。
