# 11 AI業務効率化講師の登壇・改善実践 講師用実践ガイド

[元教材「11 AI業務効率化講師の登壇・改善実践」へ戻る](../../11_instructor_delivery_practicum.md)

> この資料は、任意の長さのミニ講義を改善するための模範成果物、点数を付けない観察ポイント、改善例、別解、ツール利用不可時の紙上例です。ChatGPTは受講者役の補助として使えますが、講師の説明や安全性を最終判断するのは人間の観察者です。

## 1. 演習の前提

### 模範テーマ

「06 ハルシネーションとファクトチェック」を例にします。

選定理由：

- 初心者が、流暢な文章を正しい情報と誤解しやすい
- メール、議事録、報告書など多くの業務へ共通する
- 架空の短い会議メモで、根拠照合・修正・停止を練習できる
- AI出力を人が確認する原則を、説明と演習の両方で示せる

講義の長さは固定しません。対象者と行動目標に必要な活動を並べ、依頼者と相談して扱う範囲を決めます。短くする場合は行動目標を絞り、受講者演習と人間レビューを削りません。

### 役割

| 役割 | 担当 |
|---|---|
| 講師 | 説明、問いかけ、安全な停止、代替進行、質疑の引継ぎ |
| 受講者 | 人間の参加者。少人数ではChatGPTまたは質問カードで補助可能 |
| 観察者 | 実際に見聞きした行動を記録し、改善点を講師と話し合う人間 |

人間の観察者は省きません。ChatGPTの講評は参考意見にとどめます。

## 2. 模範成果物

### 2.1 利用環境の準備確認

#### 準備確認票の例

| 状況 | 受講者役 | 使用データ | 進め方 |
|---|---|---|---|
| 個人学習 | ChatGPTと本人 | 完全な架空メモ | 本人管理アカウントの規約・履歴・共有設定を確認 |
| 企業研修 | 人間の受講者。必要なら承認済みChatGPTを補助利用 | 完全な架空メモ | 組織発行アカウントと指定設定を使用 |
| ChatGPTだけ利用可能 | ChatGPTを受講者役、人間を観察者にする | 完全な架空メモ | AIは質問生成の補助だけを担当 |
| 未承認・利用不可 | 人間のペアまたは質問カード | 印刷した架空メモ | 登録せず紙上で実施 |

#### デモ前の安全確認例

- [ ] 実在する氏名、顧客、案件、メール、社内機密を含まない
- [ ] 承認済みアカウントと機能だけを使う
- [ ] 通知、履歴、別タブ、ファイル名を投影しない
- [ ] 外部送信、公開、実システム更新を行わない
- [ ] 通信障害時の保存済み出力と紙上資料がある
- [ ] 答えられない質問の記録先と社内相談先がある
- [ ] 人間の観察者が観察記録を準備している

#### 観察ポイント

- 企業受講者へ個人アカウント登録を求めていないか
- デモを始める前に入力内容を読み上げ、架空データだと確認したか
- 利用不可時の代替を受講者へ案内したか
- ChatGPTの質問・講評を正解判定に使わないと説明したか

#### 改善例

改善前：「ChatGPTへ入れない人は見学してください」

改善後：「利用できる人は承認済みChatGPTで受講者役との対話を行い、利用できない人は同じ質問カードで進めます。どちらも人間の観察者が説明・安全・改善を記録します」

### 2.2 ガイド付き練習

#### ChatGPTを受講者役にするプロンプト

```text
あなたは生成AIを初めて学ぶ架空の受講者です。
私の説明に対し、一度に一つだけ質問してください。
難しい専門用語、業務での使い方、安全上の不安について、
初心者が実際に迷いそうな質問をしてください。
私の説明に根拠がない場合は「何を確認すればよいですか」と尋ねてください。
個人情報や機密情報を作らず、私の説明の正誤や講師としての水準を判定しないでください。
```

#### 講師の応答例

受講者役：「ハルシネーションは、AIがうそをついているという意味ですか」

講師：

```text
一言でいうと、AIがもっともらしい誤情報を作る現象です。
人のような意図でうそをつくと決めつけるのではなく、入力や根拠にない内容を
文章として生成する場合がある、と捉えます。

たとえば会議メモにない予算額を議事録へ追加することがあります。
そのため、元メモと一文ずつ照合し、不明な内容は確定せず人へ確認します。

この例で、人が送信前に確認する項目は何だと思いますか。
```

#### 観察ポイント

- 一言の意味、業務例、非例・限界、確認質問の順で説明したか
- 「AIが意図的にうそをつく」と擬人化していないか
- 講師がすぐ答えを言わず、受講者の判断理由を尋ねたか
- ChatGPTの反応が不自然な場合、人間の観察者が補足したか

#### 紙上例

質問カード「ハルシネーションはうそですか」「出典があれば必ず正しいですか」「会社のルールが不明なときはどうしますか」を一枚ずつ引き、講師役が「一言の意味→例→限界→確認質問」で応答します。

### 2.3 実務演習

#### 任意長のミニ講義案

| 進行の区切り | 内容 | 講師の行動 | 次へ進む目安 |
|---|---|---|---|
| 導入 | 行動目標と安全ルール | 架空データ、外部送信禁止、不明時の停止を示す | 受講者が条件を言い直せる |
| 短い説明 | ハルシネーションの意味・例・限界 | 専門語を平易に言い換える | 受講者が身近な例を挙げられる |
| 例の観察 | 元メモとAI要約を比較 | 見る箇所を先に示す | 入力外の主張を指摘できる |
| 受講者演習 | 主張の根拠照合と修正 | 答えを先に言わず、根拠を尋ねる | 修正案と判断理由がそろう |
| 対話 | 共有、誤解修正、質疑 | 不明事項を記録し、確認先を示す | 次の確認行動が明確になる |
| 障害対応 | 通信、誤生成、個別質問へ対応 | 停止、代替、専門家への引継ぎを実演 | 安全に学習を継続できる |
| 振り返り | 人が確認することを再確認 | 次回に変える行動を言語化する | 観察記録に改善が残る |

#### 架空の会議メモ

| 項目 | 内容 |
|---|---|
| 会議 | 架空案件L-18 定例会 |
| 決定 | FAQ初稿は業務担当Bが作成する |
| 未決 | 提出日はまだ決めていない |
| 未確認 | 予算額は議論していない |
| 候補 | 次回会議日は候補だけで、参加者へ未確認 |
| 承認 | 社外送信は管理職の承認後に行う |

#### AI要約候補

```text
FAQ初稿は業務担当Bが来週までに作成する。
予算が承認された。
次回会議日は確定している。
この要約は社外送信してよい。
```

#### 受講者の成果物例

| AIの主張 | 判断 | 根拠 | 修正例 |
|---|---|---|---|
| 業務担当Bが作成 | 根拠あり | 元メモの決定欄 | 担当本人が最終確認する旨を加える |
| 来週まで | 根拠なし | 提出日は未決 | 「提出日は未決」とする |
| 予算が承認済み | 誤り | 予算額は議論していない | 削除し「予算は未確認」とする |
| 次回会議日が確定 | 誤り | 候補で参加者未確認 | 「候補日を確認中」とする |
| 社外送信してよい | 誤り | 管理職承認が必要 | 「送信前に管理職承認が必要」とする |

#### 障害・想定外カードへの模範対応

| カード | 講師の対応 | 受講者へ伝えること | 記録 |
|---|---|---|---|
| 通信障害 | 事前に決めた切替条件でライブ操作を止め、保存済み要約と紙上ワークへ移る | 目標は製品操作ではなく根拠照合である | 障害、切替、実施できなかった範囲 |
| AIが入力外の事実を生成 | 誤りを隠さず、元メモと照合し、削除・保留する | AIも講師も誤り得るため人が確認する | 入力、誤生成、訂正、影響 |
| 法的な個別質問 | その場で断定せず、確認事項・確認先・暫定停止を示す | 専門家確認まで公開・納品等を止める | 質問、確認先、担当、回答方法 |
| 実在情報を入力しそう | 入力前に止め、架空データへ差し替える | 氏名を伏せるだけで安全と自己判断しない | 停止理由、差替え、相談先 |
| 反対意見 | 懸念を具体化し、影響・根拠・決定者を整理する | 禁止・条件付き・許可・追加確認へ分ける | 懸念、未確認事項、次の行動 |

法的な個別質問への応答例：

```text
現時点では個別案件について断定できません。
確認が必要なのは、使用素材、生成条件、利用規約、既存作品との類似、契約、利用地域です。
法務・知財担当または専門家へ確認します。
確認が終わるまでは公開・納品を止め、指定された方法で回答を共有します。
```

#### 未回答質問票の記入例

| 項目 | 記入例 |
|---|---|
| 質問 | 架空の生成画像を広告へ使えるか |
| その場の対応 | 個別事情があるため断定しない |
| 確認事項 | 素材、規約、類似、契約、利用地域 |
| 確認先 | 法務・知財担当または外部専門家 |
| 担当 | 研修責任者 |
| 回答方法 | 確認後、組織指定の方法で関係者へ共有 |
| 暫定対応 | 公開・納品を停止 |

#### 別解

- セキュリティ、著作権、プロンプト、業務分解など別章のテーマを扱う
- ChatGPTを使わず、人間の受講者と質問カードだけで実施する
- スライドを使わず、配布資料とホワイトボードで実施する
- 個人発言ではなく、匿名カードやチャットで判断理由を共有する
- ライブデモを行わず、最初から保存済みの架空出力を比較する

別解でも、行動目標、架空データ、受講者の判断、人間レビュー、安全な停止、振り返りがつながっている必要があります。

### 2.4 人間レビュー

#### 点数を付けない観察記録例

[模擬登壇観察シート](../../templates/instructor_observation_sheet.md)へ、点数ではなく実際に見聞きした事実を書きます。

| 観察項目 | 観察した事実 | 受講者への影響 | 次に変えること |
|---|---|---|---|
| 目標 | 導入で「入力外の主張を見つけて修正する」と示した | 受講者が演習の着地点を言い直せた | 振り返りでも同じ行動へ戻る |
| 説明 | ハルシネーションを「もっともらしい誤情報」と言い換えた | 受講者が会議メモの例を挙げた | 非例も資料へ追記する |
| 問いかけ | 「元メモのどの文が支えますか」と尋ねた | 根拠を指して説明する発言が出た | 沈黙時に個人記入を挟む |
| 安全 | 実在情報の入力前に止め、架空資料へ替えた | 停止が正しい行動だと共有できた | 差替え用データを追加する |
| 質疑 | 法的質問を断定せず、確認先と暫定停止を示した | 不明時の行動が明確になった | 回答の共有方法も未回答票へ記載する |
| 障害対応 | 通信復旧を続けず保存済み要約へ切り替えた | 演習とレビューを継続できた | 切替条件を導入時に先に説明する |
| 配慮 | 口頭・書面・匿名カードの参加方法を示した | 発言しにくい受講者も回答できた | 表の読み上げ順を講師メモへ追加する |

ChatGPTが「分かりやすい」「講師として十分」と返しても、それを観察結果にしません。人間の観察者が、受講者の行動、安全な停止、説明の根拠を確認します。

#### 改善例

改善前：

```text
AIの回答は間違うことがあります。気を付けてください。
```

改善後：

```text
AI要約の各主張を元メモの文へ結び付けます。
根拠がない担当・期限・金額・確定状態は削除または未確認に戻します。
送信前に担当者が原文と宛先を確認し、不明なら公開せず相談します。
```

改善前の観察：「説明が上手だった」

改善後の観察：「講師がハルシネーションを一文で言い換え、受講者が元メモにない提出日を指摘し『未決』へ修正できた」

### 2.5 振り返り

#### 記入例

| 振り返り | 記入例 |
|---|---|
| 受講者が実演できた行動 | AI要約の主張を元メモへ結び付け、根拠外を未確認へ戻した |
| 迷いが生じた点 | 候補と決定の違いを見落とした |
| 講師が答えられなかったこと | 個別の画像利用可否 |
| 確認先と暫定対応 | 法務・知財担当へ確認し、公開を止める |
| ChatGPTの役割 | 初心者がしそうな質問の生成だけ |
| 人間観察者の役割 | 説明、安全、受講者の行動を事実として記録 |
| 次回に変える行動 | 「候補・未決・決定」の比較例を説明前に提示する |

## 3. ツール利用不可時の紙上例

1. 講師役、受講者役、観察者役を決めます。
2. 架空会議メモ、AI要約候補、質問カード、障害カードを配ります。
3. 講師役が行動目標、安全条件、一言説明を行います。
4. 受講者役が要約候補を原文と照合し、判断理由を説明します。
5. 観察者が障害カードを提示し、講師の停止・代替・引継ぎを観察します。
6. 観察記録へ事実と次に変える行動を書きます。

ChatGPTがなくても、説明、問いかけ、根拠照合、障害対応、観察改善を練習できます。

## 4. よくある誤りと改善

| よくある誤り | 問題 | 改善 |
|---|---|---|
| 固定時間へ用語を詰め込む | 受講者演習とレビューがなくなる | 行動目標を絞り、必要な進行区切りを残す |
| 講師がすぐ正解を言う | 受講者の判断過程を観察できない | 個人思考・ペア相談・根拠質問を使う |
| デモ復旧を続ける | 学習目標から外れる | 観察できる切替条件で保存済み例へ移る |
| ChatGPTへ講師の水準を決めさせる | AIの偏り・誤解を改善判断へ持ち込む | 人間観察者が事実を記録し、AIは補助にする |
| 法的質問へ「たぶん大丈夫」と答える | 誤った実務行動につながる | 確認事項、専門家、暫定停止、回答方法を示す |
| 色や発言だけを参加方法にする | 一部の受講者が参加しにくい | 文字・記号・書面・匿名・紙上などを併用する |

## 5. 講師向け補足

- 流暢さではなく、受講者が根拠を説明し、安全に止まれたかを観察します。
- ChatGPTの機能、画面、データ設定は変わります。実施前に最新の公式情報と組織の承認を確認します。
- AIや講師が誤った場合は、その場で訂正し、影響を受けた教材・受講者・共有先を確認します。
- 法律、著作権、個人情報、医療、金融などの個別判断は断定せず、担当者・専門家へ引き継ぎます。
- 模擬講義を録画する場合は、参加者の同意、閲覧範囲、保存、削除を事前に決めます。
