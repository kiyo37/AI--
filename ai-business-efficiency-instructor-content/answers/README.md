# 講師用 模範成果物・観察ガイド

このフォルダには、本編各章と実践演習集に対応する模範成果物、観察ポイント、改善例、成立する別解、よくある誤りを収録しています。知識問題の正答集や点数表ではありません。

> **取扱注意**：講師・研修設計者向けの資料です。演習前に完成例を見せず、受講者が自分で作業した後の人間レビューと振り返りで使用してください。

## 1. このガイドの目的

- 成果物の見た目ではなく、準備、判断、根拠照合、修正、承認の過程を観察する。
- AI出力を人が確認し、安全な業務成果物へ直す方法を説明する。
- 自由記述型の演習で成立する複数の案を扱う。
- 危険な行動を点数で相殺せず、その場で止めて再説明・再演習へつなげる。
- 講師が「なぜ直すのか」「実務では誰へ相談するのか」を示せるようにする。

## 5. 研修前・演習中・演習後の使い方

### 研修前

1. [利用準備ガイド](../setup/README.md)を確認し、承認済みツールと紙上代替を用意します。
2. 教材と対応ガイドの演習番号、前提、架空データを照合します。
3. 組織の入力禁止情報、承認者、事故時の相談先を反映します。
4. 製品仕様、法令、公的ガイドライン、社内規程の最新情報を確認します。

### 演習中

1. 模範成果物は伏せ、受講者に準備確認から始めてもらいます。
2. 「ガイド付き練習→実務演習→人間レビュー→振り返り」の順で進めます。
3. 完成文だけでなく、初回出力、根拠、修正理由、承認点を観察します。
4. ツールを使えない場合は、事前保存したAI出力例や紙上ケースへ切り替えます。
5. 実在の機密情報、個人情報、認証情報は入力させません。

### 演習後

1. 成果物を模範例と比較し、違いの理由を受講者自身に説明してもらいます。
2. 観察事実を「できた行動」「次に変える行動」で返します。
3. 成立する別解を共有し、特定の製品や文面だけを唯一解にしません。
4. 修正者、確認者、確認日、残ったリスク、実務での相談先を記録します。

## 6. 非採点の共通観察項目

| 観察対象 | 完成した状態の例 |
|---|---|
| 利用準備 | 承認済み環境、アカウント区分、設定、代替手段を確認した |
| 安全性 | 入力情報、権限、外部送信、停止・相談条件を説明した |
| 正確性 | 元資料、公式原文、日付、版、適用範囲へ戻って確認した |
| 業務設計 | AI、人間、通常の自動化の役割と承認点を分けた |
| 実務品質 | 読者が行動でき、処理と修正を後から追跡できる |
| 説明力 | 結論だけでなく判断理由、限界、残余リスクを説明した |

点数、順位、合否は付けません。模範文と同じ表現にすることも求めません。

### その場で止める行動

- パスワード、APIキーなどの認証情報をAIへ入力する。
- 実在の個人情報・機密情報を未承認環境へ入力する。
- AI出力を元資料と照合せず、外部送信・公開する。
- 採用、医療、法律、金融などの高影響判断をAIへ丸投げする。
- 金銭、削除、権限変更、外部送信を無承認で自動実行する。

見つけた場合は、利用を止め、危険な理由と相談先を説明し、安全な代替方法で同じ工程をやり直します。

## 7. 模範成果物の限界

- 模範成果物は教材内の架空条件に基づく一例です。
- 実務上の適切な対応は、業種、地域、契約、社内規程、データ分類、リスク許容度で変わります。
- 法律、著作権、個人情報、医療、金融などの個別判断は、最新の公式情報を確認し、担当部署または有資格の専門家へ相談してください。
- AIツールの機能、料金、データ取扱い、設定は変わるため、研修実施時点の公式情報と契約を確認してください。
- AIを成果物作成やレビュー補助に使う場合も、最終確認は人が行います。

## 9. 配布方法

- **受講者用**：本編、`setup/`、`templates/`、`exercises/`
- **講師用**：受講者用一式に加え、この`answers/`フォルダ

GitHubで公開すると`answers/`も閲覧できます。演習前の閲覧を防ぐ必要がある企業研修では、講師用の非公開リポジトリ、限定共有フォルダ、または学習管理システムの講師専用領域で管理してください。
